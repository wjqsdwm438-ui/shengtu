# 课程视觉生产工具 V2.7｜开发中快照

## 快照性质

这是 **2026-08-14 的未完成开发快照**，用于换电脑继续开发、阶段测试和人工试用。

它不是正式发布版，不是便携安装版，不代表 6 个 Skill 已在新电脑的 Codex 中注册或启用。本快照没有擅自修改原项目的业务规则、路径、Skill 元数据或历史测试证据。

## 包内内容

- `项目源码\`：当前工具源码原样副本。
- `交接资料\01_本阶段使用说明.md`：开发态如何使用。
- `交接资料\02_已知问题与待改进.md`：当前缺口和风险。
- `交接资料\03_下一阶段优化与开发方向.md`：后续开发建议。
- `交接资料\04_快照验证记录.md`：本次检查结果和验证边界。
- `SNAPSHOT_MANIFEST.json`：文件数量、排除项和构建信息。

为避免无意义缓存干扰，ZIP 不包含 `.git`、空的 `.agents`、`__pycache__` 和 `.pyc`；规则、脚本、测试输入和现有测试日志均保留。

## 新电脑上继续开发

### 1. 解压

ZIP 可以解压到任意临时目录。真正的项目根目录是解压后的 `项目源码` 文件夹。

如果希望暂时兼容当前文档中写死的旧路径，请把 `项目源码` 文件夹本身移动或重命名为：

```text
D:\codex\skills-v2.7
```

也就是最终应直接存在 `D:\codex\skills-v2.7\_shared`、`D:\codex\skills-v2.7\scripts` 等目录，而不是多套一层 `项目源码`。若新电脑没有 D 盘，可以使用任意目录，但必须把实际根目录明确告诉 Codex；不要在未评审前批量改路径。

### 2. 作为工作区打开

在 Codex 中打开：

```text
<解压目录>\项目源码
```

本阶段优先采用“工作区内显式读取 Skill”的开发方式，不要直接复制到全局 `%USERPROFILE%\.codex\skills`。

### 3. 第一次提示

```text
这是课程视觉生产工具 V2.7 的开发中快照，项目根目录是：<实际绝对路径>。
先读取 _shared/course-visual-production-v2.7.md 和当前阶段 SKILL.md。
不要把磁盘上存在的 Skill 当成已安装启用；不要修改全局配置；本次只做开发态测试。
```

### 4. Python

4 个 Algorithm Lite 脚本使用 Python 标准库。建议 Python 3.10；无需安装 requirements。

```powershell
python --version
python -m py_compile .\scripts\build_srt_index.py .\scripts\check_text_budget.py .\scripts\check_layout_skeleton.py .\scripts\score_page_complexity.py
```

没有 Python 时，Markdown 规则仍可人工使用，但 Algorithm Lite 不能执行。
