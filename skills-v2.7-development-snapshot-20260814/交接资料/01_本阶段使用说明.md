# 本阶段使用说明｜开发态

## 1. 当前可做什么

当前 V2.7 已具备较完整的 S/A/A审/B/T/C 规则链，以及 4 个可运行的轻量脚本。适合：

- 人工或 Codex 辅助完成阶段卡片。
- 使用固定样例验证文字预算、A01 骨架和复杂度。
- 用真实小任务发现规则冲突和字段遗漏。
- 继续完善元数据、路径、测试和发布方式。

暂不适合：无人值守全链生产、全局自动安装、把输出直接当最终交付。

## 2. 开发态调用方式

未正式安装前，不要假设 `$stage-*` 能被 Codex 自动识别。请显式要求读取文件。

### S线：SRT/脚本媒介分流

```text
读取 <项目根目录>\_shared\course-visual-production-v2.7.md，
再读取 <项目根目录>\stage-sline-srt-media-routing\SKILL.md。
按 S线规则处理这份 SRT，保留时间码，按语义合并，输出 S01-S08 路由和是否进入 A线。
```

只把 S07 默认送入 A线；教师出镜、真实素材、录屏、字幕包装等路线应保留为有效生产选择。

### A线：课程视觉页方向和 A审

```text
读取共享总控和 stage-aline-course-visual-routing\SKILL.md。
基于已确认的 S07 内容，先输出用户可读的当前判断、主要问题和三版方案，
再保留内部 A01-A21、文字预算、素材政策、参考图继承、冻结字段、风险和 Gate。
不要写平台提示词。
```

### Algorithm Lite：确定性证据

```powershell
python .\scripts\build_srt_index.py .\tests\sample_short.srt --out-dir <临时输出目录> --block-seconds 18
python .\scripts\check_text_budget.py .\tests\text_budget_low.txt
python .\scripts\check_layout_skeleton.py .\tests\layout_skeleton_pass.json
python .\scripts\score_page_complexity.py .\tests\complexity_low.json
```

Algorithm Lite 只给建议和证据，不能覆盖用户要求或冻结字段。`layout_skeleton_fail.json` 返回退出码 2 是预期行为。

### B线：两个生产候选

```text
读取共享总控、page_preset_bank.md、B线 SKILL.md 和已通过 A审的交接卡。
输出方案A稳妥版、方案B探索版；说明真实差异、生产风险和首选 T线候选。
不得改写 A线冻结字段。
```

### T线：提示词翻译

当前按详细 `SKILL.md` 执行：默认只翻译一个首选方案为 Image2 英文执行提示、负面提示和局部修改模板。只有用户明确要求时才扩展即梦和 nanobanana。

```text
读取 T线 SKILL.md 和已通过的 B线交接卡。
按 Image2-first 默认模式输出一个首选方案，不要自动扩展三平台。
```

### C线：Image2 视觉样张反馈

```text
读取共享总控、视觉样张状态规则和 C线 SKILL.md。
先做偏差预测；生成或审查后只标记视觉样张状态。
局部修改必须输出 keep_items、change_only_items、forbidden_changes 和 minimal_revision_prompt。
```

## 3. 推荐开发节奏

1. 一次只验证一条阶段链路。
2. 使用真实输入维护任务 Manifest。
3. 记录在哪个阶段退回、为什么退回。
4. 先修契约和路径一致性，再扩展新功能。
5. 每次修改后至少运行 4 个脚本的语法检查和现有正反例。

## 4. 必须询问用户的情况

- S08 媒介证据不足。
- 页面含义、必须上屏文字、参考图角色或素材授权不明确。
- 上屏文字超过 180，拆页或无字骨架尚未决定。
- B线无法保留冻结字段。
- C线局部修改会改变结构或页面含义。
- 用户没有确认视觉样张，却要求进入最终交付。
