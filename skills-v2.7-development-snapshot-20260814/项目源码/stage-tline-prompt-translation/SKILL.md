# T线：GPT Image 中文提示词转译

## 渐进式读取

### 必读
- 当前 `SKILL.md` 与 B线交接中唯一首选候选；若首选不唯一，先按本 Skill 的选择规则收敛。
- 不默认读取共享总控、其他候选全文、模板、示例或 `legacy/`。

### 按需读取路由
- 一次只允许由当前唯一未决问题触发一个来源；读取后先执行快速确认，再决定是否扩展下一项。
- 请求模型、背景、Alpha、文字策略或局部修改合同存在歧义时，只读 `references/gpt_image_prompt_rules.md` 的对应小节。
- 方案包含Remotion透明前景或拆层Gate时，只读 `_shared/remotion-asset-handoff-rules.md` 的对应合同。
- 只有需要输出或校验完整 T线合同结构时，读取 `templates/t_line_gpt_image_prompt.md`。
- 只有出现局部修改保护缺失或合同失败时，读取一个直接匹配的 example/anti-example。
- `legacy/` 仅限用户明确要求迁移、审计或历史追溯，当前提示词生产不得读取。

### 快速确认
确认唯一首选方案、冻结项、文字策略、参考策略、背景模式和输出格式。字段充分后停止读取并转译；缺失会改变页面依据的字段时退回 B线。

### 停止规则
完成一套中文合同后停止，不读取 C线、不执行生图、不为可能的失败预读诊断资料。

## 职责
T线只把 B线交接卡转译为 GPT Image 执行合同。它不得重新切分文字、发明课程概念、改写冻结字段、扩大创意授权或执行图像生成。

## 输入
接收 B线通过的 `方案A_稳妥版` 和/或 `方案B_探索版`，只处理标记为 `recommend_to_T_line: yes` 的方案。

## 唯一默认模式
- 只选择一个首选方案。若 A、B 均推荐，优先采用可执行性分数更高或失败风险更低者；仍相同时采用 B线 `preferred_T_line_candidate`。
- 只输出一套中文 GPT Image 提示词合同，不输出英文版、第二候选方案提示词或任何平台变体。
- 目标能力固定写 `GPT Image`，请求模型写 `gpt-image-2`。
- `实际执行模型` 只有在执行工具或 API 的明确回执中出现时才填写；T线阶段通常写 `未报告`，不得把请求模型冒充实际模型。
- 始终包含中文执行提示词、中文负面约束、输出设置和中文局部修改模板。
- 参考锁定任务必须保留B线选定的真实参考路径、确认状态、模板版本、逐字可见文字和上下文隔离合同。不得把真实路径压缩成“参考原图”。
- 参考锁定任务固定为 `reference_attachment_required: yes` 和 `text_only_execution_forbidden: yes`。

## 参考锁定带字页
- 主任务是GPT Image直接生成单一完整画布，不是分层合成第一版。
- 全部文字由GPT Image生成，并必须逐字匹配B线冻结内容；不得静默切换为确定性文字覆盖。
- 初次生成后最多两次局部文字修订。合同必须保留相同参考路径和隔离上下文，不得引入历史会话图片。

## 输出设置与 Alpha
- 完整课程视觉页的背景默认 `opaque`。
- 只有素材层、人物或物体抠图、可叠加组件等明确需要 Alpha 的任务才使用 `transparent`，格式必须为 `png` 或 `webp`。
- `transparent` 属于预览能力；不得承诺所有环境稳定支持透明通道。
- 经用户Gate确认的Remotion透明前景必须使用 `transparent` 和 PNG；不得降级为不透明输出。
- 不需要主动决定时可使用 `auto`，但完整课程视觉页不得用 `auto` 绕过默认不透明规则。

## 中文局部修改模板
必须包含 `保留项`、`仅修改项`、`禁止修改项` 和 `最小修改指令`。局部修改不得改变 A/B线冻结依据，也不得升级为整页重绘。

## 禁止事项
不得执行生图；不得把视觉样张称为定稿；不得接入 API、密钥或新增依赖；不得输出历史平台提示词。历史平台材料只保存在 `legacy/platform-prompts-v2.7.0/`，不属于当前运行依赖。

## 失败与退回
若生产字段缺失、硬禁项超出范围、参考图策略不清楚，或生成提示词必须改变冻结结构，则退回 B线。

## 最小示例
模板与示例均按上面的触发条件读取。真实参考路径在转译中丢失时，读 `anti_examples/reference_path_dropped_failure.md`；不要默认读取。
