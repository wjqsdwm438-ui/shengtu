## 背景规则
- 完整课程视觉页：默认 `背景: opaque`。
- 素材层、抠图对象或可叠加组件：有明确 Alpha 需求时可用 `背景: transparent`，并选 `png` 或 `webp`。
- 透明背景目前是预览能力；合同必须保留降级为不透明背景的可能。
