# B-Line Production Handoff Rules

## Input
A-line frozen handoff card and A-review pass result.

## Output
Two production handoff cards: `方案A_稳妥版` and `方案B_探索版`.

Exception: an explicit A16 fixed-master task outputs one `方案A_参考锁定版`. Exploration is `not_applicable` because alternate layout invention violates the user request.

## Reference-Locked Gate
Require a confirmed reference set, primary reference path, template identity, exact visible text, and context isolation. If PSD is unavailable, require the one-time flattened-PNG fallback confirmation.

Never pass an entire folder to C-line. Never omit the selected paths. Never claim pixel identity for generative full-page work.

## Text Accuracy
All visible text is generated by GPT Image and must match `must_show_text_verbatim`. Allow initial generation plus two local text revisions. Persistent mismatch is `text_generation_failure`; do not silently switch to deterministic text overlay.

## Remotion Boundary
The primary output remains a complete with-text page. Transparent foreground is only proposed after animation-risk prediction or external Remotion failure, and requires an explicit user Gate after the full page becomes `final_course_visual`.

## Difference Requirement
The two schemes must differ in at least one of: structure, material policy, composition, visual strategy, or risk profile. They must not be synonym rewrites.

## Stop Conditions
Return to A-line when frozen items are missing, reference inheritance is unclear, text budget Gate is unresolved, material preservation conflicts with AI redraw, or ALG-B01 says a candidate cannot preserve the A-line basis.

## Handoff To T-Line
Only candidates marked `recommend_to_T_line: yes` enter T-line. B-line does not write platform prompts.
