# 示例：按真实资产能力限定设计

对 `E:\shengtu\智能物流\样片版式\版式1.psd` 及其 PNG 变体完成实际检查后，B线这样记录实现依据：

- `asset_used`：`版式1.psd`、`版式1纯背景.png`、`版式1位置.png`、`版式1变化1.png`、`版式1变化2.png`、`通用标题.png`；
- `what_it_proves`：画布外壳、标题锚点、大内容容器和已有实例所展示的有限排法可用；
- `what_it_does_not_prove`：空白大内容区不能证明任意复杂图表、精确图文占比或全新的内构图能够稳定生成；
- `highest_risk`：把示例页的具体排法误当通用模板，导致教学关系与容器不匹配；
- `representative_calibration_required`：代表页为 `yes`，先验证当前教学关系在该外壳中的可读性。

对 `版式2背景.png`、`版式2背景+框.png`、`版式2背景+框+通用标题框.png`、`版式2变化1.png`，B线另行说明：完整背景自带飞机、船、卡车、无人机和控制室等强物流语义，不是中性通用背景；不透明内容框相对能抑制干扰，半透明框仍可能让背景与正文竞争。`版式2变化1.png`只证明一个具体实例，不能自动升级为全课程骨架。

示例中的合规做法：B线只把资产直接支持的外壳与锚点记作已证实，同时自行完成内层主视觉、关系结构和阅读顺序这一份主方案；内构图效果尚未证明则记为待代表页校准，而不是把结构设计留空交给C。没有通过固定图片比例制造虚假确定性。此文字示例不证明当前任务的真实教学或成图效果。
