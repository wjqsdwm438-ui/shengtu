# 示例：有教学关系证明的局部骨架继承

源页与当前页都解释“订单处理的四步顺序”，均使用从左到右的四节点路线作为语义视觉载体。B线填写：

- `source_page`：已确认的代表页 KP-03；
- `same_teaching_relation_reason`：两页都表达严格的四步先后关系，每一步对应一个动作与一个结果；
- `inherited_parts`：节点连接方式、方向提示和标题锚点；
- `required_changes`：节点文字、动作图标、重点步骤及辅助说明。

成功原因：继承的是与相同教学关系直接对应的局部机制，而不是因为源页好看；当前页差异被明确保留，源页生成图也不被默认带入执行上下文。
