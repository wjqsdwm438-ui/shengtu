# 变更记录

## Unreleased｜2026-09-07 媒介判断与规则同步增量

- 在现有共享总控明确公共职责/输入输出/分支/Gate/返工/状态的权威与同步维护：阶段Skill细化合同，模板/检查不创业务门槛，drawio是同版本业务审阅视图，SVG为派生；冲突定位修正，不凭mtime或测试通过选权威。样式域优先级不压教学，库存不自动启用。
- A语义先行，分清页、页内状态与镜头，必呈不等于全时同屏；总分预览/回显按认知连续性、观察顺序与真实承载判断，不设固定页速/字数。承载包含必要图解，不只测字号；A不越权做精细构图。
- 保持 `course_visual_a_pagination/v1`、`course_visual_page_brief/v2.7` 和现有字段类型；`required_text_and_labels` 记录本页各状态必呈文字，状态分配用既有same_screen_reason/cross_page_reason/B reading_order。`context_refs` 允许本次A正文的前页回显/后页视觉预览，仍不新增旁白、正文覆盖或改变原序，不引用Non-A/批注/批准外文字。旧静态记录不自动重释为已验证动态设计。
- B区分真实外壳、局部结构、内容资产与成功能力；成熟复用省实现、不省A判断，PNG参考非参数模板，无匹配案例不阻塞内容驱动设计。完整主方案可以待首轮校准，不再以未经验证一概禁止内构图设计，也不把核心决策空白推给C；失败可调整B结构或附证据回A分页。
- 用现有字段闭合无外部资产的显式 `no_external_asset` 分支：资产与附件空清单、既有描述/证据说明理由，完整主方案、校准与授权不豁免；声明的真实文件与参考锁定主参考仍严检，不新增schema或字段。
- C按B明确交接的当前实际状态编译与验收准确文字，不把全教学任务必呈项塞入同图；静态样张不证明动态效果。现有生图、参考、代表页、修订次数与定稿Gate不放松。
- B既有状态说明完整映射全部A必呈项及其他状态去向，B/C `must_show_text_verbatim` 仅当前图准确子集；单张状态图通过不等于全页媒体/批次通过，不释放未验证状态，不以“动画稍后再补”掩盖未定设计。执行文件可用页ID加状态后缀，page_id与主链不变。
- 消除参考六类串行索批和已明确写入授权重复询问残留；Algorithm Lite字数/评分仅作描述诊断，不自动分页或新增用户Gate。同步受影响入口、共享合同、模板、检查与流程图；实际运行结果另记验证文档，不把规则/机械检查当真实教学或成图验证。

## Unreleased｜2026-09-07 分页职责收敛

- 默认从A开始，整合原S的输入整理、源定位/Non-A和素材对应能力；S仅保留显式兼容入口，不预建页面身份。
- A统一负责全文教学分析、分页相关真实承载核验、明确页界/页数与拆合比较、内部复核；取消固定独立A审，独立审者仅用户明确要求时执行，自动触发条件不在本轮定义。
- B在A确定页界内落实具体视觉设计和生产组织；分页/正文归属/教学关系问题附证据回A局部修正，纯实现问题留B。
- 源证据与页界解耦，新增最小A分页数据合同和定位/覆盖正反例；原文归属与上下文回指分开，不以固定8/9页或字段检查通过证明分页合理性。
- 同步项目入口、模板、共享路由、C必要上游称谓、两页drawio及两份SVG；生图、参考用途、代表页和定稿Gate不变。

## V2.7.1 — 开发基线收口

### 契约

- 将当前生图能力统一命名为 GPT Image，并把当前请求模型记录为 `gpt-image-2`。
- T线改为 GPT Image 中文专用合同：默认只交付一套中文执行提示词、中文负面约束、输出设置及局部修改模板。
- 区分请求模型与实际执行模型；实际模型只能依据工具或 API 回执记录。
- 完整视觉页默认不透明；仅素材层、抠图或可叠加组件按需启用 PNG/WebP Alpha，并将透明背景能力标记为 preview。
