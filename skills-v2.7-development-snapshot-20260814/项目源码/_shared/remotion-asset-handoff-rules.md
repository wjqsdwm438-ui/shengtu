# Remotion Asset Handoff Rules

## Boundary
This project may prepare and describe assets for an external Remotion workflow. It does not create Remotion code, timelines, MP4 output, or perform video rendering.

## Primary Full Page
The primary deliverable is a single-canvas, reference-locked, with-text course page generated by GPT Image. It remains `full_page_candidate` until the user confirms it as `final_course_visual`.

## Transparent Foreground Gate
Transparent foreground generation is conditional, never automatic. C-line may propose it for `animation_structure_risk` or accept `external_remotion_failure` feedback.

```yaml
transparent_foreground_gate:
  triggered_by: animation_structure_risk / external_remotion_failure
  reason:
  recommended_foreground_scope:
  user_confirmation: pending / confirmed / rejected
```

Only a user-confirmed `final_course_visual` may become the edit target. Preserve canvas size, top-left origin, text, image positions, relative scale, shadows, and layout. Remove only the fixed master regions declared by the confirmed template layer manifest.

## Transparent Output
```yaml
transparent_foreground:
  derived_from_final_visual_id:
  canvas_size:
  coordinate_origin: top_left
  background: transparent
  format: png
  alpha_required: yes
  crop_to_content: forbidden
  re_layout: forbidden
  text_change: forbidden
  image_position_change: forbidden
```

Do not degrade required Alpha output to opaque. White, gray, or checkerboard backgrounds are not transparency. Initial generation plus at most two local revisions is allowed; persistent failure returns `alpha_generation_failure` and no deliverable.

## Optional Split-Layer Gate
Deliver a full-canvas transparent foreground first. Creating title, image, body, highlight, or other independent animation layers requires a second explicit user Gate.

```yaml
split_layer_pending_gate:
  recommended_layers:
  reason:
  user_confirmation: pending / confirmed / rejected
```

Every split layer keeps the original full canvas and top-left origin. Cropping to element bounds is forbidden because it creates Remotion alignment drift.
