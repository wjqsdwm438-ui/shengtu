# Task Run Record Rules

## 适用边界

普通任务不强制建立统一 Manifest、固定目录、跨阶段总文件或新的状态系统。只有用户明确要求保存任务记录，或现有项目已经把任务记录列为正式交付时，才使用本规则。

任务记录只用于帮助后续回看决定，不是 S/A/B/C 正文的汇总容器，也不得成为各阶段不断追加内容的单文件。

`_shared/page-brief-batch-execution-rules.md` 定义的页面简报是单页正式交接接口，与本任务记录不同。任务记录不得复制页面简报正文；页面简报也不得替代跨任务运行记录。

## 最小自然语言记录

确需记录时，使用简短的自然语言清单，只保留与当前任务直接有关的项目：

- 当前阶段和当前产物；
- 输入材料的真实路径；
- 已确认的参考图及其角色；
- 必须保持的冻结项；
- 用户已经明确确认或拒绝的单项决定；
- 视觉样张是否已生成以及用户是否确认；
- 与当前产物直接有关的修订结论。
- 当前动态批次、代表页及其确认结果（仅在与本次记录直接有关时）。

不要预填无关阶段，不复制上游全文、生产卡、提示词、验证日志或下一阶段内容。视觉样张生成和用户最终确认必须分别描述；不得把“已生成”写成“已最终确认”。

## 非哈希记录

哈希属于绝对禁止项。不得计算、记录、传递或建议文件哈希、内容哈希、摘要、指纹或变相校验值。若现有输入要求哈希，停止该做法，只问：`是否改用非哈希方式记录和核对资产？`

用户确认后，仅记录参考编号、真实路径、文件名、尺寸、模板版本、参考角色和用户确认结果。模板或参考资产发生变化时，说明变化事实并向用户提出一个确认问题；不得自动迁移既有页面。

## 写入与停止

写入任务记录前，先说明准备记录什么、写到哪个文件、是否修改已有文件，以及哪些内容明确不写入；核对当前指令和有效确认。目标文件、产物及写入范围已明确授权时告知后执行，不重复问“是否按上述产物与交接方案执行”；只有未获覆盖、且会改变下一动作的写入事项才提出一个具体问题。

仅获单个记录产物授权时完成后停止，不扩大到其他阶段产物或生图。已有端到端授权时，记录完成不另造停止点，可继续其明确覆盖的阶段工作；分页、参考用途、设计变更、生图、代表页和定稿的实质 Gate 仍分别核对，不从记录写入授权推导。
