# C线失败诊断速查

优先使用共享的 `_shared/failure-diagnosis-rules.md`。本地只补充 C线执行边界：

- 原文定位、时间码、来源一致性或素材对应错误：回A输入整理，未经授权不改原稿；
- 页界、页数、正文归属、教学目标/关系、必须项或衔接错误：回A局部修正并内部复核；
- 母版、核心骨架、主视觉、参考映射、批次、继承依据或实现可行性错误：退 B；
- 提示编译、素材注入、输出参数、文字渲染或不改变语义与骨架的局部偏差：留在 C 做最小修改；
- 修复一旦要求改变教学关系、模板、核心骨架、主视觉定义或参考角色，立即停止重试；教学/分页问题回A，具体实现问题回B；
- 不以固定图片占比判定失败，不用反复整页重抽掩盖上游设计问题；
- 实际执行模型只从明确回执记录，无回执写 `未报告`。

透明交付失败时检查格式与真实 Alpha；不得降级为白底、灰底、棋盘格或其他不透明图冒充成功。
