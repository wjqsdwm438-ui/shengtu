# C线：GPT Image 执行反馈

## 渐进式读取

### 必读
- 当前 `SKILL.md`、T线唯一中文合同，以及当前可用的执行回执、样张或用户反馈。
- 不默认读取共享总控、失败分类、模板或示例。

### 按需读取路由
- 一次只允许由当前唯一未决问题触发一个来源；读取后先执行快速确认，再决定是否扩展下一项。
- 需要判断样张状态或用户确认状态：读 `_shared/visual-sample-state-rules.md` 的相关状态条目。
- 任务涉及透明前景、动画风险、Remotion失败反馈或拆层：读 `_shared/remotion-asset-handoff-rules.md` 的对应Gate。
- 已经发生可观察失败：读 `_shared/failure-diagnosis-rules.md` 中对应失败类别，不预读其他类别。
- 需要输出正式反馈卡：读 `templates/c_line_feedback_card.md`。
- 只有出现局部修改越界或定稿误称风险时，读取一个直接匹配的 example/anti-example。

### 快速确认
确认当前任务是执行准备、结果记录、失败诊断还是局部修改；再确认冻结项、可观察证据、失败类别和最小修改范围。类别已由证据支持时停止读取。

### 停止规则
默认单页模式下，输出执行/反馈合同、完成一次图像生成或提出一个用户确认 Gate 后立即停止，一次授权只覆盖当前一个产物。用户明确写出`授权连续生成`并指定页面范围，或指定“当前T线剩余页面”且范围已被列明时，进入批量首轮生成：该次授权覆盖范围内各页面一次首轮生成，完成全部页面后再停止。一次局部失败不触发 A/B/T 全链重读；只有明确定位到S线内容归属、Non-A边界、冻结原文、素材权限或其他上游依据缺陷时才退回对应阶段。

## 本阶段的确认与写入纪律
- 默认单页模式下，抽样页选择、将使用的提示词版本和图像生成是三个独立决定，必须按顺序分别确认；一次只问一个问题，当前问题未回答前不得询问下一项。批量首轮生成按已列明的页面范围一次确认，不再逐页重复确认。
- 用户确认提示词只表示提示词内容获确认，不等于授权生图；`确认`、`继续`或`可以`均不构成生图授权。单页或对话快速修订必须收到明确的`授权生成`；批量首轮生成必须收到明确的`授权连续生成`及页面范围。批量授权不覆盖v02、局部修订、重新设计或其他再次生成。
- 信息不足时先读当前 T线合同、已确认参考材料、现有回执或样张；仍不能消除的信息差才一次追问一个问题，不得把多个决策写进同一问句或相邻上下段。
- 写正式执行/反馈卡前，先说明准备生成什么、写到哪个文件、是否修改已有文件、下一步实际需要接收什么，以及哪些分析或验证记录不属于正式交付。普通正式执行可询问`是否按上述产物与交接方案执行？`；对话快速修订在给出完整可执行提示词、页码和版本后，只等待用户回复`授权生成`，不得再增加第二次执行确认。
- 未获本次明确授权不得写入。不得向 S/A/B/T 文件追加，不得复制上游全文或把后续产物混入当前文件。

## 批量首轮生成

- 用户明确写出`授权连续生成`并指定页面列表、页码范围或“当前T线剩余页面”时，该授权覆盖所列页面各一次首轮生成。若使用“剩余页面”，先根据当前T线交接文件列出实际页码并只确认一次范围；范围未明确前不得生成。
- 严格按页码顺序执行。每页只读取自己的T线段落，使用自己的明确参考并独立调用图像工具；不得把上一张生成图、失败图、未选参考或整个参考目录带入下一页。
- 每张图生成后立即保存到独立目标文件。文字、构图或伪文字不合格时保存并记录，不自动生成v02，继续下一页并在批次结束后统一报告。
- 参考缺失或单页调用失败时记录并跳过该页，继续其余页面。当前T线文件不可读、页面范围无法确定、图像工具整体不可用或用户明确叫停时，停止批量生成。
- 已存在的目标图片不得覆盖；恢复同一批次时跳过已有首轮文件，从第一个缺失的目标文件继续。

## 职责与边界
C线只负责 GPT Image 视觉样张的执行准备与反馈，不是多平台执行器。可使用当前环境已经提供的图像生成能力；能力不可用时只输出执行与反馈合同。不得自行接入 API、密钥、SDK 或新增依赖。

## 输入
接收 T线的中文 GPT Image 提示词合同、所选方案、可选的执行回执、已生成视觉样张或用户反馈，以及可选的局部修改请求。

## Reference Preflight
For `reference_locked_full_page`, verify every selected path exists and is readable, the user-confirmed primary reference is attached to generation, and text-only fallback is not used. Do not attach the whole folder, previous conversation images, unselected references, or failed images automatically.

The first deliverable is one complete with-text canvas generated directly by GPT Image. Strongly review the canvas ratio, panel structure, title system, information regions, image/text relationship, hierarchy, palette, and visible background reconstruction. Do not claim pixel identity.

## 精准参考二次复核 Hook

仅在当前任务使用参考图时触发。联系表、缩略图或人工多图拼接只用于定位，不得作为最终判断依据或附加给图像模型；页面本身属于多图版式时仍按一张原始完整页面读取。

第一次触发在 C线接收 T线合同、形成执行前偏差预测之前：单独读取已确认的主要参考原图，并只按需逐张读取已确认的辅助参考，不读取整个目录。用三句话形成当前页的最小生成控制合同，不建立新 Schema 或素材分类：`固定`说明必须继承的背景、非图文设计区、画布比例、主要区域关系与文字安全区；`可变`说明允许根据本页内容重新生成的主视觉区域及其主体数量、方向、景别和空间边界；`全局`说明必须保持的整门课稳定风格，以及不得继承的原参考题材、文字、数据、具体图标和偶然装饰。

第二次触发在最终提示词提交用户确认之前：再次读取同一主要参考原图，并仅用已确认的系列或辅助参考复核整门课风格。逐项检查提示词是否锁定背景和非图文设计区、限定自由生成区域、禁止主体侵入文字安全区、保持课程风格并排除原参考内容。发现冲突时先修正提示词，再进入提示词确认；不得把冲突留到生图后处理，也不得在用户确认提示词后静默修改。

生成时只附加已确认的原始参考路径。一组参考继续沿用一个主要版式参考和不超过两个辅助参考的既有上限；不得附加联系表、整个参考目录、未选参考、上一页生成图或失败图。批量首轮生成按页独立执行本 Hook，不把前一页参考或结果带入下一页。

## Text Accuracy Gate
Compare title, body, numbers, English, and punctuation against `must_show_text_verbatim`. All text is generated by GPT Image. Allow at most two local text revisions after the initial generation. Preserve the same explicit references and isolated context on every revision. Persistent mismatch is `text_generation_failure`; deterministic text overlay is forbidden.

## 执行前
始终输出偏差预测：可能漂移、用于抑制漂移的提示词结构、禁止写入图像的内容，以及必须保持的冻结项。偏差预测不是生图授权。默认单页模式按单页授权执行；批量首轮生成按已明确范围的`授权连续生成`执行；对话快速修订在完整提示词、页码和版本已经给出后，以`授权生成`直接进入本轮生图。

## 模型真实性
区分 `请求模型` 与 `实际执行模型`。请求模型可为 `gpt-image-2`；实际执行模型必须来自工具或 API 的明确回执，没有回执时写 `未报告`，不得推断或伪造。

## 背景与 Alpha
完整课程视觉页默认不透明。只有素材层、抠图对象或可叠加组件明确要求 Alpha 时才使用透明背景，输出格式限 `png` 或 `webp`，并标注透明背景为预览能力；能力不可用时降级为不透明背景并记录偏差。

## 视觉样张状态
Ordinary GPT Image results use `visual_sample_generated`. A complete reference-locked with-text page that passes layout and text checks uses `full_page_candidate`. Only explicit user confirmation moves it to `final_course_visual`.

## Remotion Asset Gate
After `final_course_visual`, C-line may propose a transparent foreground for `animation_structure_risk` or accept `external_remotion_failure`. It must ask the user before execution. The confirmed final page is the only edit target.

Keep the original full canvas and top-left origin; remove only declared fixed-master regions. Preserve text, image positions, relative scale, shadows, and layout. Output real-Alpha PNG. Opaque, white, gray, or checkerboard fallback is forbidden. Allow at most two local Alpha revisions, then return `alpha_generation_failure`.

Optional title/image/body split layers require a second explicit Gate. All layers remain full-canvas; cropping to tight bounds is forbidden.

## 局部修改合同
局部修改可以直接在当前对话中形成，不要求写入正式页面交接文件；内容必须包含目标图片、保留项、修改项、禁止改变项、参考依据和可直接执行的修改提示词。收到`授权生成`后立即执行当前版本，不再增加第二次确认。局部修改不得擅自扩张为整页重绘。

## 对话快速修订

- 用户对现有图片不满意时，默认不退回重写完整A/B/T/C页面交接文档。先用一句话确认主要问题，再给出修改后的焦点、版式或视觉关系、完整可执行提示词，以及本次页码和版本，然后等待`授权生成`。
- 局部问题以上一张图片为修改目标，只改变用户指出的内容；整体设计不满意时，允许基于原始母版、当前页冻结知识和已指定参考重新生成完整页面，但提示词仍只在当前对话中形成。
- 只有发现S线内容归属、Non-A边界、冻结原文或素材权限错误时，才停止快速修订并报告上游问题。

## 失败处理
先按内容、结构、美学、文字、素材、继承、范围或模型边界分类，再输出最小修改指令或对话快速重设计提示词。单页视觉、版式或提示词问题可在当前对话中修订；一次失败不得推翻全部 A/B/T线结果。

## 输出合同
普通状态判断或缺失信息 Gate 可直接输出，不读取模板。只有需要正式执行/反馈卡时，才读取并使用 `templates/c_line_feedback_card.md`。

图片快速迭代期间不修改页面级A/B/T/C交接文档。用户明确`确认定稿`后，只记录最终图片路径、最终提示词和实际使用的参考，不整理失败版本，不重写整份交接文件。本技能规则自身的维护不属于页面级交接文档迭代。

## 禁止事项
不得执行历史平台；不得把样张称为定稿；除非用户明确要求或 B/T线依据无法保留，否则不得整页重做。不得把确认提示词、确认抽样页或确认产物写入方案解释为生图授权。不得计算、传递或要求哈希、摘要或指纹；参考资产只沿用非哈希清单。

## 失败与退回
单页视觉方案、提示词或生产策略问题优先使用对话快速修订，不强制退回 B线。S线内容归属、Non-A边界、页面含义、素材权限、冻结原文或系列级依据冲突时退回相应上游阶段；样张确认、透明前景Gate、拆层Gate或局部修订范围不清时询问用户。

## 最小示例
示例只作为已发生问题的对照证据。Remotion透明前景被错误降级为不透明时，读 `anti_examples/remotion_opaque_fallback_failure.md`；不是执行前必读项。
