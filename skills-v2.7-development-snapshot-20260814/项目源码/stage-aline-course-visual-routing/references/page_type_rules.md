# Legacy A-Line Page-Type Boundary

`A01-A21` 是旧版视觉路由标签，不再属于 A 线活跃合同。本文件仅为兼容识别而保留，A 线不得读取它来选视觉页型或精细设计。A 仍须核验分页所需的必要载体与承载条件，但不能让旧页型标签替代该判断。

当旧产物包含 `internal_page_type_top1`、`internal_page_type_top2` 或 A01-A21 时：

1. 仅回收其背后可被源材料支持的教学目标、教学关系和必显项。
2. 不将旧页型作为已确认的布局或模板。
3. 不把相邻页型改写为多套视觉候选。
4. 保留可核对的获准空间/素材限制作为 A 分页证据，具体视觉实现留 B；发现页界问题归 A 局部修正。
