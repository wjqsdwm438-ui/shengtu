# 反例：A 线提前冻结视觉方向

错误做法：A 线输出多套“稳妥、精品、现代”视觉方案，让用户选择配色、构图、母版变体、图文比例或参考图继承方式，然后把选择当作已证明可实现的设计。

为什么错：这些决定需要真实模板、成功/失败样本和生成能力证据，属于 B 线。A 线过早冻结会强迫 B/C 实现纸面方案，造成返工。

正确做法：A 完成全文教学分析、必要承载核验、实际拆合比较与明确分页，在每页记录教学目标、关系、必显项、图像教学任务和禁止偏移。可以查获准模板空间与素材限制来支撑页界，但不提前确定精细视觉方案，也不把判断交给用户补做。正常内部复核包含整套页界/邻接合并/替代方案和正文覆盖，不另设固定 A 审 Gate。
