# Stage S-Line Compatibility Source Preparation

## 交互 Gate：先判必要性，再提问

- “核对/快速确认/逐项检查”默认是模型内部工作，不等于逐项向用户索批。提问前先核对当前指令、有效确认和本地证据；相同对象、版本、用途和范围没有变化时沿用，不换名称重问。
- 只有存在会改变下一动作的用户专属决定或缺失授权才提问；必须说明具体未决项、已有结论、推荐方案、影响及被阻塞动作。不能说明回答将改变什么，不得阻塞。
- 一次一个问题约束的是实质决策，不是把一个完整方案拆成机械确认链。先给出可审阅的具体方案；同一范围内的路由清单可随分页方案一并审阅，不另问“是否继续/是否进入下一线”。
- “执行全流程/按规则自行执行到停止点”覆盖所请求范围内的分析与阶段推进；没有实质 Gate 时继续。正式文件写入仍核对目标和写入范围；范围已明确授权则告知后执行，未覆盖才询问。该授权不等于批准尚未展示的分页、设计、参考用途、生图或成品。
- 有效分页、参考用途、设计变更、明确生图授权、代表页确认和最终定稿 Gate 均保留。用户拒绝重复回答不是同意待决方案；回查批准范围，删除重复问题，只保留真正未决的差异。
- 阶段完成先报告结果；仅当授权已用尽或遇到实质 Gate 时停止。本节限定本文“立即停止/只问是否执行”的适用条件，不能用单步默认覆盖明确端到端授权。出现交互冲突时按需读 `_shared/interaction-gate-rules.md`。

## 兼容入口与分页权责

- 默认课程视觉流程不设置独立 S。本文只在用户明确要求 S/单独输入整理，或需要读取历史 S 规则时使用；默认由 A 直接完成本文的源输入职责，再做全文教学分析、必要承载核验、明确分页及内部复核。
- 单独输入整理只保留源证据、输入角色、素材和 Non-A/A 路由范围；源片段用于寻址，不是教学页，不创建 `page_id`，不向 A 预交一套教学分页。历史 S 区保留只读引用，旧 `confirmed` 只对应原明示范围，不证明旧页界、旧单元数或页数可沿用。
- 有效处理范围、Non-A/A 正文范围、执行分页及其他授权分别沿用；不把内容准入等同于分页批准，不要求先批准候选页数才能由 A 分析。
- A 对全文做实际拆合比较，收敛时建立页面 ID；有证据可以保留原边界，不默认继承旧候选，也不为重审而硬改页数。B/C 不自行改页界，发现页数/正文归属/教学关系问题须给证据交 A 局部修正。
- 源输入错误默认由 A 输入整理职责局部修正，原证据及更正依据保留；不要求重启独立 S。源证据与分页方案在现有 A 分析产物中分开记录，按需读 `_shared/pagination-authority-rules.md`。

## 渐进式读取

### 必读
- 当前 `SKILL.md` 与用户提供的 SRT、讲稿、单页内容或素材清单。
- S 线核对来源文本和素材是否存在，但不查看母版以推导页面设计，也不接收已有页面的构图作为路由依据。
- 不默认读取共享总控、A/B/C Skill、版式细则或视觉示例。

### 按需读取路由
- 一次只允许由当前唯一未决问题触发一个来源；读取后先执行快速确认，再决定是否扩展下一项。
- 只有 S01-S08 相邻路由仍无法区分时，读取 `references/srt_media_routing_rules.md` 的对应条目。
- 只有用户明确要求时间线索引、确定性证据或 ALG-S01 时，读取 `_shared/algorithm-lite-rules.md` 的 ALG-S01 小节并执行对应脚本。
- 只有明确请求单独输入整理产物，或需要核对历史 S 区结构时，读取 `templates/s_line_segment_card.md`；不创建新的预分页简报。
- 只有已经出现字幕过切风险时，读取 `anti_examples/srt_over_split_failure.md`；已经出现跳过用户确认或用估算代替用户决定时，读取 `anti_examples/pagination_confirmation_skipped_failure.md`；已出现 S 线越界设计时，读取 `anti_examples/s_line_overdesign_failure.md`。

### 快速确认
每次读取后内部核对：源文范围及角色、时间码证据、原顺序、可用素材、路由和未决项。一个路由已有充分证据且不存在用户专属未决决定时，停止扩展读取。

### 停止规则
本入口没有默认阶段停止点。用户只请求单独输入整理时，完成该范围后结束；用户请求 A 或全流程时，输入整理属于 A 内部工作，不因使用了兼容路由或得到 S07 而停下索问“是否进入 A”。

## 职责边界

S 线只负责为后续设计提供可追溯输入：

- 按原顺序整理连续源范围，保留原文、时间范围和来源行；必要的寻址切片不代表教学分页。
- 记录可核对的事实、数据、专有名词及它们的来源。
- 盘点已有图片、视频、截图、文档等素材及其可用状态。
- 判断教学片段是否需要视觉辅助，选择 S01-S08 媒介路由。
- 记录源引用、输入角色、真实素材与路由范围；沿用已有产物，不强制新增独立档案或 `page_brief`。历史 S 区保持证据引用，不静默改写。

S 线不负责页面设计。`visual_assistance_need` 只说明“需要帮助学习者看懂什么”，不能转写为构图、图片占比、容器数量、母版变化或平台提示。

## 阅读与单问题确认顺序

- 本地源文和素材能够消除的信息差先通过只读检查消除；不得把可从 SRT、讲稿或素材清单查明的问题转给用户。
- 先判断当前路由是否确实依赖音频、实际时长或时间码；只有缺少业务必需的时间证据时，才按依赖顺序一次追问一项。无时间轴的文档任务在现有时间字段明确“不适用”及理由，不强要音频、不估算时长。
- 证据齐备后分别核对 Non-A 与 A 正文范围及其有效批准；已批准范围直接由 A 分析。只在范围有真正歧义时问用户，不制造一套 S 候选页数让用户先批，也不机械逐项索批。
- 本入口不输出冻结分页或教学候选分页；只在明确写入授权内记录源输入。用户提交的旧候选可作历史比较依据，留给 A 从全文检验，不能用 S 区 confirmed 代替分页依据或授权。

## DOCX / DOC 多媒体接收

- 先利用用户原稿、已有脚本、素材目录及设计节点产物读懂整体，不强制清洗成统一表格、逐张拆图或重新誊写；节点中的设计决定留给所属阶段核对，不能反向决定 S 路由。
- 保留原文、原顺序与定位，分清旁白正文、屏显文字、制作批注、素材需求和实际已有媒体。原旁白不得改写，批注和制作指令不得混入旁白。
- DOCX 核对正文位置、内嵌/浮动图的关系与锚点、批注范围及其所指内容，不能仅凭解包序号给图片配段落；链接、缓存图与原媒体分别判断。
- “插入视频”“引入盲降的原理视频”等文字只记需求；“图片或视频”仍是未定选项。实际文件已提供且可读、对应内容核对后才记 available；缺文件记 missing，关联或内容未核对记 unverified。
- DOC 解析不足时先局部核对，必要时仅在工作副本本地转 DOCX；位置、裁切或关联仍影响含义时再查看页面预览。未验证的精确排版、浮动图或批注关联必须明示，不宣称完整视觉读取或专业事实已证实。
- 原文、锚点、时间或素材缺口在输入记录中明示，默认由 A 输入整理职责处理，只阻塞受影响内容；无法可靠路由时用 S08，不让下游猜测，也不要求整课重做。核对原文忠实性与素材对应，不新增外部真实性/实时专业审校关口。

## Routes
`S01_教师出镜型`, `S02_教师出镜+课程页辅助型`, `S03_视频/现成素材展示型`, `S04_图片/现成素材展示型`, `S05_软件界面/屏幕录制型`, `S06_后期字幕/标注包装型`, `S07_AI课程视觉页型`, `S08_人工确认型`.

## Must Rules
- 不得把 `.srt` 逐句分页。
- 保留相邻字幕的原顺序与连续源证据及 `segment_time_metadata`；教学拆合和正式页界由 A 基于全文判断。
- 不把不需要视觉化的内容强制送入 AI 图像生成。
- 纯过渡或可由教师直接讲清的内容不默认纳入课程视觉分页。
- 真实事件、品牌案例、现场表演、展馆空间、软件操作、截图和字幕包装通常保留 Non-A 去向，不强制转成 AI 视觉页。
- 需要长时间停留的课程主页、案例解释页、关系性内容或系列课程页可纳入课程视觉分页；默认 A 仍处理所有源输入。兼容字段 `enter_A_line` 只表示视觉分页归属，不是单独 S 阶段准入 Gate。

## 禁止项

S 线不得输出或冻结：

- 页面构图、布局骨架、内容容器或精确位置；
- 图片占比、文字区间或任何固定比例；
- 母版、模板或参考图的继承与变化策略；
- A 线页面设计、B 线生产卡、C 线执行提示或平台提示词；
- 以视觉风格、上一页效果或已有构图决定 S 路由。

## 源输入交接（不预建页面）

普通路由结论直接写在已有输入/A 分析产物中；仅明确请求单独整理时使用 `templates/s_line_segment_card.md` 的源记录格式。

记录源路径/版本/定位、原顺序、原文及输入角色、时间证据、素材可用状态、视觉辅助需求、路由及理由、有效范围及批准依据。只按需要使用 `segment_id` 寻址；它不是 `page_id`，不表示一页。不得在输入模板中预填 A/B/C 页面、页数或教学分页。

历史 `s_section` 保留原貌作源引用，A 不复制出改写版“S 摘要”。新页面仅在 A 方案收敛后建立，与源记录通过明确映射连接。

## 正式产物与修改返回

写入前说明将整理什么、写到哪份已有产物、是否修改文件，以及 A 如何引用源证据而非继承页界。

已有授权明确覆盖当前文件及范围时不重复询问；否则仅询问未覆盖写入。只请求单独整理时完成后结束；A/端到端请求按原授权继续，无独立 S Gate。源输入问题默认交 A 对应职责更正并保留证据，B/C 不在自己分区改写；用户明确请求修订旧 S 记录时保留原版本与依据。

## Failure / Return
当源材料歧义、当前路由必需的时间码或素材证据缺失、强行路由可能浪费生产成本时，使用 `S08_人工确认型`，且只询问当前缺失的一项决定。
