# 反例：混淆内容准入与分页冻结

错误一：缺少实际时间证据时编造时间码，并直接冻结分页。
错误二：把处理范围、Non-A、A线清单、分页理解为必须连续提问四次；用户已批准范围后仍换名重问。
错误三：用户只批准进入A的正文范围，模型却要求先批准8页才能进行A教学复核。
错误四：旧 S 区为 confirmed，模型直接以旧九单元/旧 page_id 逐页补卡，并称已完成全文重新分页。
错误五：先在 S 生成一套教学候选页，再要求 A 只能逐页复核；或为了证明重新分析而强行改变原页数。

正确做法：默认直接由 A 整理输入和有效 Non-A/A 正文范围；无时间轴的文稿标明时间码不适用。源记录不预建教学页，旧候选只作待检验基线。A 从全文目标、关系、主次依赖及必要承载证据做实际拆合比较，再建立收敛页面和真实源映射；原界有证据可保留。内部复核查整套页界、所有邻接关系、合理替代和正文覆盖。未获具体分页批准不得当作执行分页已批准。批准 Non-A 不等于批准其制作方式，拒绝重复回答也不等于批准8页。提交审阅的方案须有逐字起止、源定位及可核验正文，摘要不能代替边界。
