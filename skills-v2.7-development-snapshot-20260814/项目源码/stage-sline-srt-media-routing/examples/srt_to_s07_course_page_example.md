# Example: SRT To Source Evidence (Not Predetermined Pages)

Input: `00:01:20-00:02:05` 连续解释两个市场活动区如何共同支撑一个节庆教学点，并提供了两处场地的真实照片。

A 默认输入整理（或用户明确请求的 S 兼容整理）正确输出：

- 连续源范围说明：同一教学对象与连续解释；仅用于证据寻址，不意味着它正好是一页。
- `s_route: S07_AI课程视觉页型`。

- 保留原文、时间码、来源行、素材对应和有效范围，不建立 page_id 或教学候选页。
- A 请求内继续全文分析、必要承载核验与拆合比较；如果用户只请求单独输入整理，完成所请求范围后结束，不设置额外 S Gate。
