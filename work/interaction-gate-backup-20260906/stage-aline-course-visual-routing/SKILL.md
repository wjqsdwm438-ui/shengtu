# Stage A-Line Teaching-Semantic Contract

## 渐进式读取

### 必读
- 当前 `SKILL.md` 与已由用户确认的 S07 共享页面简报；用户明确指定 A 线时，可使用其单页内容作为源证据。
- 首先核对 `s_section`的原文、时间码、事实、素材和路由状态。发现错误时返回 S，不在 A 区改写。
- 不默认读取 S 线 Skill、共享总控、母版、版式、B/C Skill、页型表或视觉示例。

### 按需读取路由
- 一次只允许由当前唯一未决问题触发一个来源；读取后先执行快速确认，再决定是否扩展下一项。
- 内容关系容易被误写成固定布局时，读取 `references/layout_decoupling_rules.md`。
- 必须呈现的教学文字、口播文字与可省略内容边界不清时，读取 `references/onscreen_text_rules.md`。
- 真实照片、截图或证据素材的事实意义不清时，读取 `references/material_retention_rules.md`。
- 只有需要正式交接时才读取 `templates/a_line_page_handoff_card.md`；只有需要正式 A 审报告时才读取 `templates/a_review_report.md`。
- 已经出现 A 线越界决定版式、比例或多套视觉候选时，只读取 `anti_examples/assistant_freezes_visual_direction_failure.md`。

### 快速确认
每次读取后立即确认：教学目标、教学关系、必须呈现项、图像教学任务、禁止语义偏移项和唯一未决 Gate。上述内容都有直接证据时停止读取。

### 停止规则
A 区或 A 审结论完成后停止，不自动读取 B/C，不决定模板、骨架、生产批次或生成方式。页面不应进入 A 线时立即返回 S 线。

## 职责

A 线回答“这一页为什么需要这样表达”，只冻结教学语义合同：

1. `teaching_goal`：学习者看完应理解、区分或完成什么。
2. `teaching_relation`：页面内容之间的真实关系，例如比较、步骤、因果、组成、映射、场景解释；必须用句子说明关系参与者和方向。示例是开放提示而非互斥枚举，可复合、可跨页；分类、组成、条件等关系可同时成立，不强塞一个标签。
3. `must_show_items`：必须准确呈现的文字、数据、专有名词、标签或真实素材。
4. `image_pedagogical_task`：图像必须帮助学习者识别、对照、追踪、定位或理解什么；不用“更好看”代替教学任务。
5. `forbidden_semantic_drift`：不能被省略、合并、反转、虚构或变成装饰的语义。

A 线不是视觉设计线。它不需要通过母版或参考图证明内部构图，也不需要生成多套候选让用户进行审美选择。

## 共享页面简报

- A 线必须打开 S 已创建的同一份 `page_brief`，保留 `page_id`、`original_course_order` 和整个 `s_section` 不变，只填写 `a_section`。
- 不得新建脱离 S 证据的“A 线摘要”，不得为简洁而改写源文或必显事实。
- B 线后续只能追加 `b_section`；对 A 语义有疑问时返回 A，不在 B 区自行释义。
- 正式结构使用 `templates/a_line_page_handoff_card.md`。

## 分析与确认顺序

`S0 核对S区 -> S1 教学目标 -> S2 教学关系 -> S3 必须呈现项 -> S4 图像教学任务 -> S5 禁止语义偏移 -> S6 单一语义Gate -> S7 追加A区`

- 先核对用户已有教学目标、设计说明等节点产物的来源、版本/日期和有效确认范围，沿用有依据的语义，只补缺项。只有教学意图证据不足、约束冲突或拟改已确认语义时才询问用户，一次只问一项。
- 专业约束由当前具体内容触发，注明所约束的对象、标注/图例、条件和依赖页面；工程中的论证、空间等约束可共存，不按学科名排他套规则。串起“原文 → 教学目标 → 内容关系 → 必呈信息 → 图像任务”，来源未核实不得写已验证。
- 不询问配色、左右布局、图片大小、母版变体、参考图视觉继承或“稳妥/精品/现代”等视觉选项。
- 结论允许为“当前证据不足”，但必须说清缺少的语义证据；不得以无证据的设计细节填补空缺。

## 禁止项

A 线不得输出或冻结：

- 页型、主载体、精确布局、构图、容器数量或尺寸位置；
- 图像占比、文字占比、固定图像建议区间或由输出分辨率推导的内容比例；
- 多套视觉方案、审美推荐或以视觉效果为主的用户 Gate；
- 模板选择、模板变体、局部骨架继承、生产批次、参考图的视觉映射方案；
- B 线生产卡、C 线执行提示、GPT Image 指令或可实现性的无证据承诺。

可以记录输出技术尺寸作为项目元数据，但不能用它推导图像或文字应占多少空间。

## A 审

A 审先核对同一简报 S/A区、源定位、已有设计节点产物的版本/日期、页面对应、有效确认范围和未决项。完整且匹配的已有产物可作为闭合依据，不要求重做设计；有文件或字段非空不等于通过。A 审只审教学与事实：

- 教学目标是否可从源材料支持；
- 教学关系是否明确且方向正确；
- 必须呈现的文字、数据、专有名词和真实素材是否完整；
- 图像教学任务是否服务学习目标；
- 禁止语义偏移项是否能阻止事实错误、概念反转和不当省略。

A 审不检查页面是否“更美”、不评选视觉方案、不以图片占比或模板匹配作为通过条件。结论沿用 `通过`、`局部补卡` 或 `退回A线`；退回时以 `return_target` 明确实际责任为 S 或 A，不把源证据问题留给 A 猜。

每个通过项要有可查证据；旧版本、批注当旁白、媒体需求当实际素材、数值冲突或缺原图，只退相应项并注明受影响页。局部补卡仍由 S/A 所属分区维护，再复核受影响项；A审不得另发替代上游的更正稿，不代选版式。证据齐全且目标一致的检查项自行判定，只有关键决定无依据或语义冲突才提问；正式写入仍需落在现有授权范围内。

## 正式产物与修改返回

写入正式产物前，先说明将在哪一份共享页面简报中追加 `a_section`、是否修改已有文件、B 实际接收什么，然后只问：`是否按上述产物与交接方案执行？`

已有授权明确覆盖当前文件、分区及写入范围时不重复询问；否则取得用户明确确认后才写入。写完立即停止，不得顺带生成 B/C 内容。原文、时间码、事实或素材错误返回 S；教学目标、教学关系、必显项或禁止偏移错误返回 A。

## Failure / Return
如果 S 路由不应为 S07，返回 S线。如果教学目标、教学关系、必须呈现项或真实素材的语义作用无法从证据确定，停止并只请用户确认当前一项，不用视觉设计规则替代缺失证据。
