# Template Realization Evidence Rules

## 基本原则

模板只能证明其实际提供的能力。也就是说，模板只能证明已观察到的结构和能力：外层母版不等于内层版式，空白主内容框不能证明复杂构图可以稳定实现，单张变化样例不等于可稳定复用的通用模式。前期证据不足时应降低设计精度并通过代表页校准，不能以更多描述、固定比例或更多候选掩盖不确定性。

B线每页都应简要记录：实际使用资产、它能证明什么、不能证明什么、最大实现风险、是否需要代表页校准。依据必须来自当前真实文件或已经确认的直接相关样张；文件名相似或视觉观感接近不是能力证据。

## 生成能力边界

OpenAI 官方图像生成说明将精确构图、文本放置和跨次一致性列为仍可能失误的场景；生产提示指南建议使用清晰分段，显式区分保留项与修改项，并以小范围修改迭代。由此得到的执行规则是：前期不得冻结超出模板、直接参考和代表页结果所能证明的微观布局；C线不得以连续整页重抽代替局部修改或 B线返工。

- 官方限制说明：<https://developers.openai.com/api/docs/guides/image-generation>
- 官方提示指南：<https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide>

## 版式1样片边界

已核实资产包括 `版式1.psd`、`版式1纯背景.png`、`版式1位置.png`、`通用标题.png`、`版式1变化1.png` 和 `版式1变化2.png`。

- `版式1.psd` 为 1920×1080 的浅层母版，主要只有全画布、标题区域和大内容区域三个结构层级。它能证明外框、标题锚点和主内容安全区，不能证明任何具体内层排版。
- `版式1纯背景.png`、`版式1位置.png` 和 `通用标题.png` 是外层壳、标题位置或独立标题资产；不能据此推导图片数量、图文比例、流程图、比较图或精确组件布局。
- `版式1变化1.png` 只证明该壳曾容纳一个大型内容区中的图文组合；其长文本和虚线框不构成通用标准。
- `版式1变化2.png` 只证明该壳曾容纳上下堆叠的比较表达；只有当前页同为相同教学关系和相同语义载体时，才能作为局部参考。

## 版式2样片边界

已核实资产包括 `版式2背景.png`、`版式2背景+框.png`、`版式2背景+框+通用标题框.png` 和 `版式2变化1.png`。

- `版式2背景.png` 含飞机、货轮、卡车、无人机和控制室等强物流主题，不是中性背景；用于无关主题或信息密集页时存在语义污染和注意力竞争风险。
- `版式2背景+框.png` 的不透明大内容框能更有效压制背景干扰，可证明外框和内容安全区，不能证明内层构图。
- `版式2背景+框+通用标题框.png` 的半透明内容框仍暴露主题背景；必须验证正文和主视觉不会与背景竞争，不能默认作为通用正文母版。
- `版式2变化1.png` 只提供一个左侧视觉、右侧文字的实例。其课件感、背景竞争和长文本处理不得升级为系列通用规范。

上述文件是本次规则形成的审计证据，不构成项目运行时对外部绝对路径的依赖。实际任务必须记录并附加用户当前提供的真实资产路径。

## 使用决策

- 先核对并沿用用户已确认、与当前目标匹配的设计节点产物，依次判断原样复用、仅换内容、必要局部调整；确实不兼容才重新设计。固定项、可变项和禁止继承项均从当前真实依据确定，只换内容不重做外层设计。
- 静态截图只证明观察到的画面，不能证明 AE工程可编辑、参数或时长可变、运动质量或生成稳定性。待批归档不参加实现判断；参考许可也不等于原素材使用许可。

- 先确定教学关系，再判断哪个模板能力与该关系兼容；不得因模板可用而反向改变教学关系。
- 母版外壳可以早期冻结；内层精确位置、图片大小、装饰、光影、次要物体和局部留白，只有在直接参考或代表页结果证明后才冻结。
- 变化样例只能继承已明确匹配的局部机制；不得整页照搬，也不得因“效果好”跨教学关系传播。
- 证据无法支持复杂设计时，B线输出最小可执行方案并注明开放项，由 C线代表页验证；失败后退回 B线调整，不继续累加提示词。
