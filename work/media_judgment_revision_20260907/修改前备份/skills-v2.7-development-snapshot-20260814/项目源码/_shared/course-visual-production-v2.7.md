# Course Visual Production V2.7.1 Shared Control

## 定位
V2.7.1 是用于课程视觉样张生产的 Markdown Skill 规则系统。当前流程以教学语义和真实实现证据约束前期设计，默认采用 A/B/C 职责；A整合原S必要输入能力、分页与内部复核，S和独立A审不再作为固定阶段；原 T线不再是独立设计或交接阶段，其提示编译、素材注入和参数校验能力并入 C线执行适配器。项目不得修改源码根目录之外的全局 Skill 配置。

## 主流程
```text
SRT / 脚本 / 单页内容 / 参考图 / 失败图 / 局部修改请求
-> 输入类型识别
-> A线输入整理、全文教学分析
-> A内必要承载核验、明确分页与内部复核（不是独立阶段）
-> B线可执行设计及动态分批
-> C线执行适配器
-> C线生成或同结构局部修改
-> 按课程原顺序组装
```

生产顺序不等于课程顺序。课程页码和原始顺序必须始终保留用于追溯与最终组装；实际生产由 B线按可验证的同类机制动态分批。

## 阶段职责

- A线：整合输入整理，保留源定位/顺序/Non-A与素材证据；通读全文识别教学目标、关系、主次和依赖；在分页时纳入获准模板空间、必呈信息负荷、素材限制和必要载体；形成明确页界/页数与拆合理由，并完成内部复核。
- A内部复核：检查整套边界、相邻合并、合理替代、衔接、承载依据和原文覆盖；不是独立A审阶段。独立审者仅用户明确要求时执行，自动触发条件本轮不定义。
- S兼容工具：仅显式请求时提供输入整理/时间索引/媒介路由，不预先冻结或建立页面身份，不作为默认A准入条件。
- B线：沿用A明确分页和语义要求，落实具体模板/容器、精细构图、完整主视觉、文字实现、参考映射、动态批次和校准开放项；新承载问题涉及分页时提供证据交A局部修正，不成为第二分页中心。
- C线执行适配器：校验当前源引用、A分页版本和B方案、真实素材路径及参数冲突；将已确认设计编译为一套GPT Image中文提示，不补做设计。
- C线生成与局部修改：沿用原授权与反馈合同。仅在教学关系、模板和核心骨架不变时局部修改；需要改变时按责任回A/B，不反复整页重抽掩盖前期问题。

Algorithm Lite是伴随确定性检查，不证明分页合理性或成图效果，不恢复固定比例、固定批数或独立T线。

## 分页权责与状态分离

- 默认A统一完成输入整理、教学分析、必要承载核验、明确分页和内部复核；取消默认独立S与固定独立A审。S仅为显式兼容输入工具，不先给A一套必须沿用的页界。
- **范围批准是A分析准入条件，分页批准不是A分析前置条件。** 源文证据稳定保留，页界/页数由A依据全文关系与真实承载条件形成；旧候选和旧审核通过不自动继承。
- A内部复核必须查页界必要性、相邻合并、合理替代、衔接及覆盖，不只查单元内部自洽；独立审者仅用户明确要求时执行，触发条件本轮不定义，不新增停止点。
- B只落实具体视觉设计和生产组织；涉及页界、页数、正文归属或教学关系时提供证据交A局部修正，纯实现问题留B。原文和准入未变不重跑S，不默认重启整链，不把设计缺口交给用户补做。
- 分页方案须有源路径/版本、逐字起止（均含）、精确定位、明确页序/页数、拆合比较与承载依据；源引用与页面身份解耦。正式页修订保留旧新映射及有效状态，详见 `_shared/pagination-authority-rules.md`。

## 单一页面简报
源文证据独立于页面身份，保留在原稿和现有A分析记录中；A形成分页后每页使用一份贯穿A/B/C的页面简报。各阶段维护自己的分区，源文以精确引用保留，不复制、改写或概括上游正文：

- 源证据：路径/版本、正文/备注/Non-A范围、必要时间码及素材对应；新任务不要求S区或先建page_id，旧S区只作历史引用；
- A 区：当前分页引用、教学目标/关系、必呈项、图像任务、承载依据及当前整套分页内部复核的引用；
- B 区：模板与实现证据、唯一主方案、参考映射、动态批次、代表页、骨架继承证明及故意保留的开放项；
- C 区：适配后的提示、实际注入资产、技术参数、校验结果、执行回执和局部修改记录。

页面简报不是统一 Manifest、跨页总文件或全文归档。完整结构、动态批次和交接规则见 `_shared/page-brief-batch-execution-rules.md`。

## 实现证据边界
A先读懂全文教学关系，并在分页阶段查看当前用途获准的真实模板与素材，将可用空间、必呈文字/标签/图注负荷、素材限制和必要视觉载体纳入拆合判断；不能等A完成后才首次核验承载。B沿用可核验的A证据并补具体实现细节，不另起分页。模板约束可以影响页界，但不得反向改写教学内容关系。模板只能证明它实际提供的结构；空白内容框不能证明复杂内层构图可实现，单张变化示例也不能升级为通用布局规则。

B线必须说明：使用的真实资产、它能证明和不能证明的内容、最大实现风险、是否需要代表页校准。缺乏证据时应减少前期细节并保留为 C线校准开放项，不能通过增加规则或精确描述掩盖不确定性。指定版式1/2样片的已核实边界见 `_shared/template-realization-evidence-rules.md`。

## 动态批次与上下文隔离
- B线按外层模板、教学关系、语义视觉载体、参考依赖和生成方式的实际接近程度组织批次，不预设批数，必要时允许单页成批。
- 同一章节、页码相邻、表面风格相似或上一页效果好，都不能单独成为同批或继承理由。
- 每批先执行一张能代表该批核心教学关系和典型信息密度的页面；过度简单或特殊页面不得作为代表页。
- 代表页由用户确认后，才能展开本批其余页面。其局部骨架只在该批、同教学关系和同语义载体内成为候选锚点，不跨批自动传播。
- 同批在同一 C线对话连续执行，跨批隔离；每页坚持固定批次基准加本页差异，不把上一张结果滚动升级为基准。历史上下文不是新增指令或参考授权。

“模型舒适区”仅是需要由代表页和真实统计验证的生产假设，不得写成模型能力承诺。可依赖的控制手段只有真实证据、代表页先验验证、批内有限复用和批间上下文隔离。

## 跨页骨架继承
B线申请继承上一页或其他页面的局部骨架时，必须同时写明：来源页、两页教学关系为何相同、语义视觉载体为何相同、继承哪些骨架、当前页必须改变什么。任一项缺失即不继承。

“效果好”“风格统一”“属于同一课程”“页码相邻”均不是教学关系证明。详细规则见 `_shared/reference-image-inheritance-rules.md`。

## 非比例式设计判断
不得设置或恢复“某类页面必须使用固定图片占比”或类似区间。1920×1080 等画布规格是技术参数，不产生内容比例要求。页面只按以下问题检查：

- 图像是否承担明确教学任务；
- 主要视觉焦点是否服务学习目标；
- 文字是否清晰且阅读顺序合理；
- 信息关系是否可辨；
- 背景、装饰和参考元素是否争夺注意力；
- 必须呈现的内容是否获得足够空间。

## 渐进式读取总则
普通任务先只读当前阶段 `SKILL.md`、用户输入及页面简报中的必要上游分区，不默认读取本共享总控。只有任务涉及跨阶段状态、全流程契约、批次、迁移边界或全局术语冲突时，才读取本文件相关小节。

版式资产只按六类作自然语言检查：固定外层母版、母版预览、内层排版参考、内容或素材参考、失败诊断图、无关或拒绝参考。必须检查遗漏、重复归类、失败图误作参考及拒绝项进入下游。分类不是页面类型系统，不得由此产生固定批数、固定比例或自动套版。

每次只由一个明确未决问题触发一个按需来源；到达阶段边界、当前判断充分或必须由用户决定时立即停止扩大读取。完整机制见 `_shared/progressive-reading-protocol.md`。

## 交互 Gate：先判必要性，再提问

- “核对/快速确认/逐项检查”默认是模型内部工作，不等于逐项向用户索批。提问前先核对当前指令、有效确认和本地证据；相同对象、版本、用途和范围没有变化时沿用，不换名称重问。
- 只有存在会改变下一动作的用户专属决定或缺失授权才提问；必须说明具体未决项、已有结论、推荐方案、影响及被阻塞动作。不能说明回答将改变什么，不得阻塞。
- 一次一个问题约束的是实质决策，不是把一个完整方案拆成机械确认链。先给出可审阅的具体方案；同一范围内的路由清单可随分页方案一并审阅，不另问“是否继续/是否进入下一线”。
- “执行全流程/按规则自行执行到停止点”覆盖所请求范围内的分析与阶段推进；没有实质 Gate 时继续。正式文件写入仍核对目标和写入范围；范围已明确授权则告知后执行，未覆盖才询问。该授权不等于批准尚未展示的分页、设计、参考用途、生图或成品。
- 有效分页、参考用途、设计变更、明确生图授权、代表页确认和最终定稿 Gate 均保留。用户拒绝重复回答不是同意待决方案；回查批准范围，删除重复问题，只保留真正未决的差异。
- 阶段完成先报告结果；仅当授权已用尽或遇到实质 Gate 时停止。本节限定本文“立即停止/只问是否执行”的适用条件，不能用单步默认覆盖明确端到端授权。出现交互冲突时按需读 `_shared/interaction-gate-rules.md`。

## 最小执行原则
- 未获执行授权时保持计划状态。已有端到端授权时推进范围内分析与阶段工作，不因阶段名称改变重复索批；正式写入和生图分别核对当前具体授权，不跨越实质 Gate。
- 一次授权只覆盖一个已说明的产物。端到端授权可以覆盖整条流程，但代表页 Gate、最终样张 Gate 和发生设计改变时的退回 Gate 仍不可跳过。
- 信息不足时先读本地直接证据；只有本地材料无法回答且决定权属于用户时才询问。
- 文件存在、收藏或可打开不等于批准可用；待批、禁用、不自动导入的归档默认排除在 B/C 输入之外。AE 参考须按具体项目与用途另获批准；参考许可不等于原素材使用许可。规则实施授权不等于生产、生图或付费 API 授权。
- 先核对用户已有原稿与设计节点产物，在现有简报或确认记录中引用原路径、版本或日期、来源定位、适用页/批次、用途及未决项，不另建台账。同范围且证据仍有效的确认直接沿用，不重复询问；版本、用途、语义或继承范围改变时只重新确认受影响项。权限或证据不明先停相关动作，查已有材料后只问一个必要问题。
- 用户拥有最终设计决定权。模型可以分析和推荐，但不得静默冻结版式、参考角色、文字策略或生图选择。
- PSD 或其他分层母版不可用时，不得静默退化为扁平 PNG；说明限制并取得一次明确接受后才能继续。

## 产物与交接原则
正式写入前，说明本阶段准备追加的页面简报分区、目标文件、是否修改已有文件及下一阶段实际接收内容，并取得相应授权。后续阶段只读取和引用必要上游分区，不重新转述成另一套卡片。

页面简报是页面级正式交接接口；任务运行记录仍按 `_shared/task-run-manifest-rules.md` 管理，二者不得互相替代。验证日志、上游全文和其他页面内容不得混入当前页简报。

## 用户 Gate
先由A/B/C修正其职责内可判断的问题；只有材料仍无法回答的用户专属决定或真实授权缺口才进入用户Gate。输入缺口不因旧S08标签自动变成用户工作；B无法保持页界/教学要求时先附证据回A，C结构问题按责任回A/B，不把设计缺口交给用户补做。每批代表页通过用户确认后才能展开该批；视觉样张和最终成品仍分别确认。

用户已经确认的教学关系、模板、核心骨架、参考角色、文字政策、素材政策和禁止偏移项不得被静默推翻。系统能够推断不等于可以替用户冻结决定；提问仍遵守一次一个未决事项。

## 停止点与返工路由
- 原文定位、正文范围、来源一致性或素材关联错误：回A输入整理，未授权不改原稿；
- 页界、页数、正文归属、教学目标/关系、必呈内容或衔接错误：回A局部修正并内部复核；
- 模板、核心骨架、参考映射、批次或实现可行性错误：退回 B线；
- 提示编译、素材注入、透明度、尺寸或不改变结构的局部生成偏差：留在 C线修正。

C线一旦发现必须改变上述冻结项，立即停止重试；分页/教学关系问题回A，模板或核心骨架实现问题回B；禁止用反复整页重抽掩盖前期设计问题。诊断合同见 `_shared/failure-diagnosis-rules.md`。

## 哈希绝对禁止
不得计算、记录、传递或建议使用文件哈希、内容哈希、摘要、指纹或变相校验值。资产只用自然语言清单记录必要的参考编号、真实路径、文件名、尺寸、模板版本、参考角色和用户确认结果。

## GPT Image 输出规则
- C线执行适配器默认只形成一套中文提示词，不输出英文或历史平台变体。
- 目标能力写 `GPT Image`；请求模型写 `gpt-image-2`；实际执行模型仅在执行回执明确报告时填写，否则写 `未报告`。
- 完整课程视觉页默认不透明背景。
- 透明背景用于素材层、抠图对象、可叠加组件或经用户 Gate 确认的 Remotion 透明前景，格式限 PNG/WebP。
- Remotion透明前景必须从用户确认的 `final_course_visual` 派生；Alpha失败不得降级为不透明图。
- 旧多平台合同只保存在 `legacy/platform-prompts-v2.7.0/`，不属于当前运行依赖。

## 视觉样张规则
GPT Image普通输出默认是 `视觉样张`。完整带字参考锁定页通过C线后是 `full_page_candidate`；只有用户明确确认后才能成为 `final_course_visual`。批次代表页的确认仅满足该批展开前提，不代替其余页面列名各一次的首轮生图授权，不自动授权图像继承，也不等于最终成品确认。

## V2.6 与独立 T线迁移边界
旧 V2.6 卡片和 class-JSON 必须先通过 `legacy-v2.6-migration.md`。旧 T线提示合同只能迁移到 C线执行适配器字段，不能作为独立阶段继续流转；旧 C线提示词不得直接用于当前执行。旧 `最终交付成图` 应转换为视觉样张、带字成品候选或后期编辑对象。

## 绝对排除
不得增加 PPTX 生成、HTML 幻灯片生成、浏览器编辑器、MP4 渲染、Remotion代码或渲染、MCP、自动安装、固定页面分类、固定批数、固定图像比例、全量多代理自动化、完整图像分割工程、完整 HyperFrames 视频链或外部项目依赖。允许输出 `_shared/remotion-asset-handoff-rules.md` 定义的 Remotion 资产交接合同。
