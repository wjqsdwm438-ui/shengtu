# Example: A-Line Defers Visual Form

一段内容用来引入“仓内作业与运输环节如何衔接”。A 线不决定使用氛围图、图文页还是其他视觉形式，只写明：

- 教学目标：学习者建立仓内作业与后续运输不是孤立环节的初步认识。
- 教学关系：仓内作业的结果作为运输环节的输入，存在前后衔接关系。
- 图像教学任务：让学习者感知两个环节处于同一作业链。
- 禁止偏移：不能表达为两个并行且无关的场景。

A 同时从全文检查这段引入是否宜与后续解释同页，比较分开引入与合并解释的认知负荷；结合必显文字、获准空间与必要载体作明确分页，不能仅因“引入”就默认单占一页。具体视觉形式、构图和尺寸留 B，不能用固定图文占比反推分页。
