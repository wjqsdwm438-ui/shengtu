# A-Line Must-Show Text Rules

A 线区分三类文字：

- `must_show_text`：省略或改写会造成教学、事实或专业含义损失的文字，必须逐字保留。
- `voiceover_only`：由口播承担，不需要画面重复的内容。
- `optional_supporting_text`：可由 B/C 根据可读性取舍，但不得改变 A 线冻结的教学关系。

A 必须在明确分页前核验必显文字、术语、标签和图注的实际负荷，结合已获准模板可用空间、真实素材限制、同屏必要性和跨页依赖比较拆合方案；不能留到 B 才首次判断是否能承载。

字符数可以作为信息负荷的描述证据，但不能设固定字数上限、固定文字区间、图文占比或由分辨率反推内容比例。不能通过压缩专有名词、数据或教学句解决过载。需要改页界时由 A 局部修正分页和源映射，不返回独立 S，也不让用户补做设计判断。具体排版、字号和尺寸留 B。
