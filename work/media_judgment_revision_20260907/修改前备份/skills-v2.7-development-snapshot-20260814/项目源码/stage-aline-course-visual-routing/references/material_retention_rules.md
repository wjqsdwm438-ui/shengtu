# A-Line Real-Material Semantic Rules

- 真实照片、截图、原始数据图和其他证据素材必须与 A 输入整理的源路径/定位对应；历史 S 区可直接作为只读源引用，不要求重跑 S。
- A 线记录该素材在教学中证明什么，以及哪些主体、标识、数据或界面状态不能被重画或虚构。
- A 在分页前核验素材内容是否已真实提供、关键主体/标签能否读清、哪些区域不能裁切或分离，以及必显说明与素材是否必须同屏；将实际素材限制写入承载依据，不把需求文字当作已可用素材。
- A 不决定素材具体尺寸、位置、外框、包装或风格迁移；这些由 B 在不破坏分页及语义硬约束的前提下落实。B 发现真实素材使现有页界不可行，应提交证据交 A 局部修正，不能自行删图、改正文归属或分页。
- 失败图可用来识别语义偏移，但不是当然的视觉参考。
- 素材存在、内容对应与原文忠实性核对不等于外部事实或实时专业审校；素材用途及参考授权仍依原 Gate，不因输入整理扩大。
