# 示例：动态分批与唯一主方案

待生产的 20 页没有被按页码切成固定数量的批次。B线逐页比较外层模板、教学关系、语义视觉载体和参考依赖/生成方式后得到实际批次，其中一张特殊页独立成批。

某批共同采用同一外壳，教学关系都是“步骤推进”，语义载体都是带节点的路线，且都依赖同一组已确认图标。B线选择一张步骤数和文字密度居中的页面作为代表页，只为每页形成一份主方案。代表页确认前其余成员保持阻塞；确认后冻结路线骨架的公共部分，并保留各页节点数量、重点位置和内容密度差异。

成功原因：批次由生产机制而不是课程序号产生；代表页具有典型性；人工确认发生在扩批之前；唯一主方案没有把设计收敛责任推给 C线。
