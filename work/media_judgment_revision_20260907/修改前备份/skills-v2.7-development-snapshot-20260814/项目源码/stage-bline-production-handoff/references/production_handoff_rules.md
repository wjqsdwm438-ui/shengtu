# B-Line Executable Design Handoff Rules

## 1. 输入和唯一输出

B线读取当前源引用、A明确分页与内部复核，只向同一页面简报B区追加一份 `main_execution_plan`。B的pagination_ref必须匹配当前A计划，不要求独立S或A审报告。不复制上游全文，不制造稳妥版/探索版，也不写 C线平台提示。

固定母版任务与普通任务都遵循“一个页面、一份主方案”。固定母版只是更强的保留约束，不是另一套候选机制。

## 2. 实现依据门槛

每页用真实文件路径或案例 ID 记录：

| 字段 | 必须回答的问题 |
|---|---|
| `asset_used` | 实际看过并用于判断的资产是什么？ |
| `what_it_proves` | 它直接证明什么可以实现？ |
| `what_it_does_not_prove` | 哪些结论不能由它推出？ |
| `highest_risk` | 当前最可能导致返工的因素是什么？ |
| `representative_calibration_required` | 是否必须先用代表页验证，为什么？ |

证据按其真实能力使用：
- 纯背景只证明外层风格和可用画布；
- 标题条只证明标题锚点；
- 空白内容框只证明容器与安全区域；
- 单个成功页只证明相同教学关系、语义载体及近似密度下的局部机制；
- 失败页用于标注风险与禁止做法，不得被当成可实现范例；
- 模型能力说明只证明一般能力和限制，不能证明当前具体构图必然成功。

证据不足时允许保留 `open_for_calibration`，但不得写精确坐标、固定图片占比或未经验证的复杂内构图。若开放项会影响教学关系、模板身份或核心骨架，则不得交给 C线，必须先补证据或校准。

## 3. 动态批次判定

批次数量由页面事实产生，不设目标值。对每对拟同批页面同时比较四项：

1. 外层模板是否相同或兼容；
2. 教学关系是否相同；
3. 语义视觉载体是否相同；
4. 参考依赖与生成方式是否兼容。

四项有任一实质冲突即拆批。单页独立成批是正常结果。课程序号、章节归属、美观程度和表面色彩不参与充分性判断。

每批记录：
- `batch_id` 与成员原始课程序号；
- 四项共同依据及主要批内差异；
- 代表页与选择理由；
- 独立 C对话要求；
- 校准状态和人工确认。

每个批次都必须确认一张代表页。`representative_calibration_required: no` 仅表示当前非代表页由本批代表页覆盖，不能跳过批次校准；此时必须填写被引用的代表页。

代表页应覆盖核心教学关系、典型信息密度和主要生成风险。若没有任何一页同时具备这些条件，应先拆批，而不是选择一个失真的代表。

## 4. 代表页校准与冻结

状态机：

`calibrating → representative_generated → representative_confirmed → frozen_for_execution`

- `calibrating`：只允许代表页进入 C；其他页阻塞。
- `representative_generated`：等待人工检查教学关系、主视觉、文字、背景竞争与实现风险。
- `representative_confirmed`：写入确认人/确认事件和可复用的批次核心。
- `frozen_for_execution`：其他成员才可按独立当前页简报执行。

代表页确认冻结的是批次核心，不冻结每页所有微观构图。页间差异仍由各页教学内容决定。代表页被否决时必须更新实现依据或拆批，不能通过连续整页重抽宣称校准成功。

## 5. 局部骨架继承

允许继承必须同时满足：
- 源页已确认；
- 两页教学关系相同；
- 两页语义视觉载体相同；
- B区明确说明来源、相同原因、继承项和必须变化项。

禁止理由包括：
- 上一页效果好；
- 同一课程或同一章节；
- 需要统一风格；
- 两页都有图片或颜色接近；
- 希望节省生成次数。

证明失败时写 `decision: no_inheritance`，重新依据当前页教学关系设计；不得把源页生成图默认带入 C上下文。

## 6. 视觉空间判断

输出尺寸可作为技术参数保留。内容空间不采用固定比例区间。A已在分页期间核对同屏需要、文字/标签/图注负荷与实际空间；B沿用有效依据，只就具体安排通过以下问题补充说明：
- 图像具体帮助学生理解什么？
- 哪个信息应先看到，哪个随后读取？
- 关系结构是否比氛围装饰更突出？
- 文字和必要标签是否有真实可读空间？
- 背景、装饰、参考场景是否可能干扰？

答案形成 `visual_space_rationale`，而不是百分比。

## 7. 固定母版与参考隔离

固定母版要求已确认的参考集合、主参考真实路径、模板身份、精确可见文字和上下文隔离。只向 C线传选定路径，不传整个文件夹，不自动带失败图或历史对话图片，也不承诺生成式整页工作的像素级一致。

PSD 不可用时，记录扁平 PNG 的已知局限及一次明确确认。参考图角色必须区分外壳、布局、内容素材、风格和禁止继承项。

## 8. 停止与返工

- 源输入证据、页界/页数、正文归属或教学语义错误归A；B提供证据、影响页和问题，不自行重分页。
- B的模板、骨架、参考映射、分批或可实现性问题在 B修订。
- C只处理编译、素材注入、透明度、尺寸和冻结结构内的局部生成偏差。
- C发现需要改变教学关系、模板或核心骨架时立即停止：教学/分页问题回A，模板/骨架实现问题回B，禁止用反复整页重抽掩盖设计问题。

## 9. 交接门槛

- `main_execution_plan.outer_template.identity`、`outer_template.description` 和 `main_visual_description` 均为必填；空母版或空主视觉必须停止，C线不得自行补设计。
- `ready_for_representative_calibration`：仅供代表页首次校准。要求当前A分页内部复核完成且版本/页界匹配、实现依据五项完整、唯一主方案完整、真实路径可用、继承证明合法或明确不继承、无空字段或矛盾；允许批次处于 `calibrating` 且人工确认 `pending`。这只是交接前提，C线仍须代表页明确生图授权才可执行一次，非代表页保持阻塞。
- `ready_for_C`：用于代表页确认后的正式扩批。除上述条件外，还要求批次代表页已人工确认，状态为 `frozen_for_execution`；这不代替其余成员列名各一次的首轮生图授权，也不自动定稿或授权图像继承。
- 其他情况均为 `not_ready_for_C`。

## 10. 绝对哈希禁令

不计算、保存、传递、推荐或规范化哈希、摘要与指纹。引用清单只使用引用 ID、真实路径、文件名、尺寸、模板版本、角色和人工确认。
