# 分页权责与确认对象规范

## 本次实施边界
本规范先修正自然语言合同、准入门槛及局部返工规则。不增加新的全局状态机，不宣称已有脚本支持教学单元到页面的自动多对多映射。正式简报的拆合迁移、依赖失效检查和真实会话回归仍需专项实现；涉及已有文件拆合时先提出明确迁移计划，不静默覆盖。

## 三种对象必须分开
| 对象 | 含义 | 主责 | 不代表什么 |
|---|---|---|---|
| 源文片段 | 可逐字定位的正文范围、事实、素材及课程顺序 | S线 | 不代表最终一片段一页 |
| 教学单元 | 为完成学习目标而组织的教学关系与必须呈现项 | A线 | 不代表最终一单元一页 |
| 执行页面 | 在模板、可读性和素材证据约束下实际生产的页面 | B线形成方案，用户最终批准 | 不代表可任意改写教学关系或原文 |

S候选切分只是供复核的初稿。A可在已批准文字范围内，按教学目标、教学关系和必须呈现项复核、拆合候选分组；不得受S候选页数绑架。B先在不损害语义的前提下验证承载可行性；如需跨页拆合，提供具体实现证据与边界差异，交A复核受影响的教学连续性，不由B单方面改语义。

## 确认对象与术语
不得单独用“已确认/confirmed”概括整份交接。必须同时说明对象、来源版本或本轮引用、范围、确认依据、仍开放项。优先在现有记录中用自然语言分列以下状态，不要求用户新增填表：

- **Non-A范围已批准**：哪些原文不进入A。其制作方式是另一决定，未定不阻塞主体。
- **A线文字范围已批准**：允许A分析哪些正文，不等于候选页数获批。
- **S候选切分待A复核**：有逐字边界的初稿，不是冻结页数。
- **A教学分组已复核**：目标、关系、必须项已由A检查；不是B实现已验证，也不是用户已批准。
- **B页面方案待批准**：已结合获准真实资产提出可执行方案，须明确当前页界与风险。
- **执行分页已批准**：用户对具体版本的页界及页面方案作出明确决定；后续变化只重审受影响项。
- **生图已授权/代表页已确认/成品已定稿**：分别依现有C线规则，均不得从内容准入或分页状态推导。

用户明确批准S候选方案时，该批准仍有效；A发现问题只提出差异，不静默推翻。用户明确只批准文字范围时，A复核并提出新分组不需要再索取同一范围批准。

## 准入与冻结
**范围批准是A分析准入条件，分页批准不是A分析前置条件。** 源证据完整且用户授权继续A或端到端时，A可以使用已批准正文及S候选边界直接开始教学复核；没有正式页面简报也可先做分析，不伪造已确认S页面。

S不得冻结未经批准的最终分页，但可以在明确写入授权内保存已批准的原文证据与范围。其status即使为confirmed，也只能证明列明的S事实/范围，不能隐含最终页界获批。后续正式简报仍遵守分区所有权和原文保护。

一般流程：S批准内容准入 → A教学分组及A审 → B实现核验（必要时A/B局部协商）→ 用户审阅具体执行分页/设计 → 原有C授权与代表页Gate。无需先让用户批准一个未经教学复核的页数才能进入A；用户要求提前审阅候选分页时照办，但必须说明批准对象。

## 局部返工，不重启整链
| 问题 | 修正责任 | 复核与继续位置 |
|---|---|---|
| 原文漏段、错误来源、事实或Non-A/准入范围变化 | S | 只修受影响原文与范围；仅失效其下游依赖 |
| 教学目标、关系、必须项、教学分组不合理 | A | 局部修正，A审只审差异，再由B核验受影响页；源文未变不回S |
| 版式、载体、模板、可读性或素材实现不合适，语义不变 | B | B局部改方案；不要求A/S重做已有效结论 |
| B建议跨页拆合，可能影响教学连续性 | B提交边界与实现证据，A复核语义 | A/B只处理受影响单元及必要相邻衔接；不重跑S |
| 用户不满意 | 先从具体反馈/成图定位对象 | 不把“不满意”默认翻译为源文错误或全流程重启；只有反馈确无可定位内容才问一个必要问题 |
| 同结构执行偏差 | C | 沿原有局部修改与授权规则修正 |

一次局部差异单只记录：原对象及版本、保留项、变更理由与证据、新旧正文起止、受影响页/必要相邻衔接、需要失效的下游结论、负责阶段和真正待用户决定项。记录在现有简报/修订说明，不新增一套正文副本。源文、语义、模板、引用、批次改变时分别检查相关依赖；未受影响的批准继续有效。

S协助更新拆合后的源文定位属于局部证据维护，不是重新索取整课范围批准。阶段是责任归属，不要求用户切换对话或重新发起整条S→A→B。

## 可审阅切分最低证据
无论S候选、A重分组还是B拆合建议，都必须提供源文件及版本定位、按课程顺序的编号、逐字正文起点/终点（均含）、行号或等效精确位置、可核验的完整对应正文/原路径引用、变化理由与确认状态。只有章节标题或摘要标签不合格，不能发起分页批准Gate。变更前后须检查原文覆盖无遗漏、无重叠、不混入备课备注；源文顺序与临时候选页码不是同一对象。

## 现有契约的过渡限制
现有page_id/original_course_order按页面管理；在正式拆合映射契约及校验器未完成前，不原地重编号、覆盖旧S区或把新语义片段冒充原页。先在已授权分析记录中提出映射和局部差异；需要落正式文件时明确旧到新关系、保留路径、影响范围与写入授权。不得为规避此限制退回要求用户批准旧8页才能开展A分析。
