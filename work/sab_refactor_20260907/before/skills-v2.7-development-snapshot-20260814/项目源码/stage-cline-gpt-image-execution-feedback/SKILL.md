# C线：执行适配、生成与反馈

## 交互 Gate：先判必要性，再提问

- “核对/快速确认/逐项检查”默认是模型内部工作，不等于逐项向用户索批。提问前先核对当前指令、有效确认和本地证据；相同对象、版本、用途和范围没有变化时沿用，不换名称重问。
- 只有存在会改变下一动作的用户专属决定或缺失授权才提问；必须说明具体未决项、已有结论、推荐方案、影响及被阻塞动作。不能说明回答将改变什么，不得阻塞。
- 一次一个问题约束的是实质决策，不是把一个完整方案拆成机械确认链。先给出可审阅的具体方案；同一范围内的路由清单可随分页方案一并审阅，不另问“是否继续/是否进入下一线”。
- “执行全流程/按规则自行执行到停止点”覆盖所请求范围内的分析与阶段推进；没有实质 Gate 时继续。正式文件写入仍核对目标和写入范围；范围已明确授权则告知后执行，未覆盖才询问。该授权不等于批准尚未展示的分页、设计、参考用途、生图或成品。
- 有效分页、参考用途、设计变更、明确生图授权、代表页确认和最终定稿 Gate 均保留。用户拒绝重复回答不是同意待决方案；回查批准范围，删除重复问题，只保留真正未决的差异。
- 阶段完成先报告结果；仅当授权已用尽或遇到实质 Gate 时停止。本节限定本文“立即停止/只问是否执行”的适用条件，不能用单步默认覆盖明确端到端授权。出现交互冲突时按需读 `_shared/interaction-gate-rules.md`。

## 阶段定位

C线包含两个连续步骤：

1. **执行适配器**：校验页面简报，把 B线已经确认的唯一主方案编译成一套可执行的 GPT Image 中文提示词；
2. **生成与反馈**：按批次隔离执行、记录真实回执、检查结果，并在冻结边界内做最小局部修改。

执行适配器不是新的设计阶段。它不得新增教学关系、视觉焦点、模板、核心骨架、参考角色、配色方向或其他设计判断；字段不足时停止并退回责任阶段，不得猜测或代填。

## 渐进式读取

### 必读

- 当前 `SKILL.md`；
- 当前页共享页面简报中的 S、A、B 区；
- 当前批次清单、代表页状态和用户确认记录；
- 当前页被 B线明确选中的原始参考素材。

不默认读取其他候选、上一页生成图、失败图、整个参考目录、其他批次对话或 `legacy/`。

### 按需读取路由

- 一次只允许由当前唯一未决问题触发一个来源；读取后先快速确认，再决定是否扩展下一项；
- 需要完整执行/反馈卡时读 `templates/c_line_feedback_card.md`；
- 需要核对提示编译、素材注入、文字或输出参数时读 `references/gpt_image_execution_adapter_rules.md` 的对应小节；
- 已发生可观察失败时读 `_shared/failure-diagnosis-rules.md` 的对应类别；
- 涉及透明前景、拆层或 Remotion 交付时读 `_shared/remotion-asset-handoff-rules.md` 的对应 Gate；
- 仅在出现直接匹配的问题时读取一个 example 或 anti-example。

### 快速确认

先确认当前任务是代表页校准、批量首轮、结果反馈还是局部修改，再确认当前页 Gate、冻结项、必要参考和最小执行范围。证据已经充分时停止读取。

### 停止规则

读到足以解决当前唯一未决问题即停止扩展。一次局部失败不触发 S/A/B 全链重读；只按可观察证据退回对应责任阶段。完成当前授权范围、提出一个必要 Gate 或确认退回后立即停止。

## 输入：共享页面简报

C线直接接收一份由上游逐段追加、未经重新转述的页面简报：

- **S区**：页面 ID、课程原始顺序、原文或时间码、事实信息、可用素材；
- **A区**：教学目标、教学关系、必须逐字呈现内容、图像任务、不得偏移的语义；
- **B区**：`main_execution_plan` 唯一主方案、`implementation_evidence` 实现依据、`batch_assignment` 批次、`batch_calibration` 代表页状态、`skeleton_inheritance` 骨架继承证明和 `C_adapter_handoff` 执行交接；
- **C区**：由本阶段追加的适配校验、编译提示、实际注入素材、技术参数、执行回执和修改记录。

C线不得复制或改写 S/A/B 区。若输入仍是旧式独立提示词合同，可用于审计或迁移，但不得作为新任务的必需中间产物。

## 执行适配器硬 Gate

编译前逐页检查。以下任一情况出现即停止该页，不执行生图，也不得自行补设计：

1. 页面 ID、课程原始顺序、教学目标、教学关系、必须呈现项或 `main_execution_plan` 为空；
2. `输出设置.尺寸` 为空、残缺或不是完整具体值；
3. `main_execution_plan.outer_template.identity`、`description`、`evidence_reference_id` 或 `main_visual_description` 为空；无固定母版或无外部素材时，B区必须明确写出“无”及理由，空值不等于无；
4. B线声明要使用的母版、参考或素材路径不存在、不可读，或获准项目/用途/范围与当前使用不符、尚待批准/禁用/未选中，或实际附加素材与参考映射不一致；
5. 页面简报仍残留占位符、截断句、仅有字段名的空句，或出现相互矛盾的尺寸、背景、文字、参考角色、模板版本；
6. `implementation_evidence.asset_used`、`what_it_proves`、`what_it_does_not_prove`、`highest_risk` 或 `representative_calibration_required` 缺失；
7. `C_adapter_handoff.selected_reference_paths` 与实际附件不一致，`preserve_items` 或 `change_items` 为空，或 `unresolved_blockers` 非空；
8. B区仍有会改变教学关系、模板、核心骨架、主视觉或参考角色的开放事项；
9. `skeleton_inheritance.decision` 为 `inherit_local_skeleton`，却缺少 `source_page`、`same_teaching_relation_reason`、相同语义视觉载体的证据、`inherited_parts` 或 `required_changes`；
10. 非代表页的 `batch_calibration.state` 不是 `frozen_for_execution`、`human_confirmation` 不是 `confirmed`，或 `C_adapter_handoff.readiness` 不是 `ready_for_C`。

代表页校准是第10项的唯一例外：代表页可在主方案和素材 Gate 全部通过后，以 `batch_calibration.state: calibrating`、`human_confirmation: pending`、`C_adapter_handoff.readiness: ready_for_representative_calibration` 仅执行一次首轮校准。该例外仍须代表页一次明确生图授权，不得释放任何非代表页。字段校验通过不能证明用户真实批准、教学正确或图像效果；应核对现有确认记录与实际附件。

退回规则：原文、时间码、事实或素材清单错误退 S；教学目标、内容关系、必须呈现项或语义边界错误退 A；母版、骨架、参考映射、主视觉、批次或可实现性错误退 B。只报告实际缺口，不提出替代设计。

## 提示词编译合同

Gate 通过后，执行适配器只编译 `main_execution_plan`，并生成一套中文合同。提示应清晰、可扫读，并明确分段：

1. **页面任务**：页面 ID、教学目标、教学关系、语义视觉载体；
2. **保留项**：母版、核心骨架、标题系统、文字安全区、必须逐字文字、课程稳定风格；
3. **仅修改或生成项**：本页允许生成的区域、主体、方向、景别和内容边界；
4. **参考用途**：逐个列出真实路径、主要或辅助角色、必须继承与不得继承的内容；
5. **技术参数**：具体尺寸、质量、背景、格式、请求模型；
6. **中文负面约束**：只列与本页有关的硬禁项；
7. **局部修改边界**：保留项、仅修改项、禁止修改项、最小修改指令。

不得输出多套候选、英文版或历史平台版本。不得把图片面积比例或固定占比写成合规条件；画面空间只根据图像教学任务、信息关系、阅读顺序、文字可读性、视觉焦点和内容容纳情况描述。

目标能力写 `GPT Image`，请求模型写 `gpt-image-2`。实际执行模型只根据工具或 API 明确回执填写；无回执写 `未报告`，不得推断。

## 参考与素材注入

- 只附加 B线明确选择且 Gate 已验证的原始路径；不得只写“参考原图”；
- 不附加整个目录、联系表、缩略图拼图、待批/禁用/未选参考、失败图或隐式的最近对话图片；上一页/代表页图仅可按下述完整骨架继承证明及当前页明确选用例外附加；
- 每个参考必须明确用途以及不得继承的原题材、文字、数据、图标和偶然装饰；
- `reference_locked_full_page` 必须实际附加已确认的主要参考，禁止纯文本替代；
- B线明确写“无需外部素材”时，可不附加素材，但不得省略母版和主视觉描述。

涉及参考页时，提交提示前再次读取主要参考原图，复核画布比例、非图文设计区、主要区域关系、文字安全区、可变主视觉区域和课程稳定风格。若提示与参考映射冲突，停止并按冲突归属退 B；不得静默改写 B线设计。

## 动态批次与上下文隔离

- 生产顺序采用 B线确认的动态批次，不再默认按课程页码连续生成；课程原始顺序只用于追溯和最终组装；
- 同一批在同一个 C线对话连续执行，不同批次隔离；每页只依据固定批次基准、本页简报和当前必要参考，独立核对本页正文、图像、数据，不把上一张结果滚动升级为基准；
- 不同批次之间不得传递生成图、失败记录中的视觉内容、隐式参考或上下文偏好；
- 同批历史不是新指令或参考授权；上下文确已混杂时，只依据同一冻结基准恢复干净上下文，不改变设计、不扩大授权。同批页面也必须逐页使用自己的简报和参考。代表页图像只有在 B线明确批准其为局部骨架锚点且继承证明完整时才可作为输入；
- 每批先执行 B线指定的代表页。代表页生成结果须取得明确人工确认后，才可对该批其他页面接受一次范围明确的`授权连续生成`；
- 批量授权只覆盖指定批次、列明页面各一次首轮生成。已有目标文件不得覆盖；只有确认仅本页局部失败且共同依据无误时，才可记录后继续其他已授权页，不自动补生成或 v02。共同依据有误或影响不明，先停相关依赖页，按最早责任回 S/A/B/C，不默认全课重启；
- 批次数量和页数不得预设。C线不得因页码相邻、同一章节、视觉相似或上一页效果好而自行并批或继承。

## 骨架继承复核

骨架继承只能来自 B线明确批准。C线必须核对：

- 来源页与当前页的教学关系相同；
- 两页使用相同的语义视觉载体；
- 已写明继承的局部骨架；
- 已写明当前页必须变化的部分。

“上一页效果好”“同一课程”“同一模板”或“保持风格统一”均不是充分理由。证明缺失或仅含这些理由时停止并退 B。未声明继承时，不读取或附加上一页图像。

## 人工确认与执行授权

- 编译提示词不等于授权生图；未获明确生图授权不得调用图像工具；
- 代表页需要一次明确生图授权，生成后再取得一次“该批代表页通过”的人工确认；
- 代表页通过仅满足展开前提，不代替其余页面生图授权、不自动定稿或授权图像继承。B根据实际样张与确认维护共同基准；用户可用一次范围明确的`授权连续生成`授权该批其余页面各一次首轮生成，不再逐页要求人工审批；
- 局部修改、v02、重新生成、透明前景或拆层不在批量首轮授权内，按当前产物另行取得明确授权；
- 单批确认不适用于其他批次。

## 生成后检查

逐图查看实际成图，对照原文及 A/B冻结要求；不是沿用 B方案自评，也不把生成者的“通过”描述当效果证据。代表页还须核对典型关系、信息密度及可变边界能否支撑本批，不能以一张过简样张推断稳定。始终记录：实际附加素材、执行提示词版本、技术参数、实际模型回执、输出路径和结果状态。检查：

- 图像是否承担 A区规定的教学任务；
- 视觉焦点是否与教学目标一致；
- 数字、术语、文字是否完整、准确、可读，关系方向与阅读顺序是否清楚，有无裁切或遗漏；
- 背景、装饰和参考元素是否争夺注意力；
- 核心骨架、母版与禁止偏移项是否保持；
- 页面是否容纳全部必须呈现内容。

不使用固定图片占比或机械面积区间判断通过与否。每页检查后，按共享批次规则在现有反馈中横比代表、边界/高密度和后续页面，检查共同基准稳定及本页差异保留；批后检查不能代替逐图验收，检查通过不能代替用户定稿。

普通结果为 `visual_sample_generated`；参考锁定且版式和文字检查通过可标记 `full_page_candidate`；只有用户明确确认才能标记 `final_course_visual`。

## 局部修改边界与停止点

C线可处理：提示编译错误、素材注入错误、输出尺寸或透明度执行偏差、文字渲染偏差，以及不改变已确认语义和骨架的局部视觉偏差。

局部修改合同必须包含目标图片、保留项、仅修改项、禁止修改项、参考依据和完整可执行提示词。每次修订复用相同的明确参考与隔离上下文，不得扩张成整页重绘。文字初次生成后最多两次局部文字修订；持续失败记为 `text_generation_failure`，禁止确定性文字覆盖。

若修复需要改变教学关系、模板、核心骨架、主视觉定义、参考角色或批次依据，立即停止重试并退 B；教学语义或必须呈现内容有误退 A；原始内容或素材事实有误退 S。不得用反复整页重抽掩盖设计问题。

## 背景、Alpha 与 Remotion

- 完整课程视觉页默认 `opaque`；
- 只有素材层、抠图对象或可叠加组件明确需要 Alpha 时使用 `transparent`，格式限 `png` 或 `webp`；
- 经 Gate 确认的透明交付必须验证真实 Alpha。能力不可用或验证失败时记录失败并停止，禁止用白底、灰底、棋盘格或其他不透明输出冒充；
- Remotion 透明前景和可选拆层继续遵守共享 Gate；所有层保持完整画布与左上角原点，不得裁成紧边界。

## 模型、哈希和写入纪律

- 不自行接入 API、密钥、SDK 或新增依赖；
- 不计算、传递或要求哈希、摘要或指纹；资产只使用非哈希清单和真实路径；
- 不向 S/A/B 区回写。C区只追加本阶段事实，不重新整理上游全文；
- 快速迭代期间不改页面简报的冻结区；用户确认定稿后，只记录最终图片、最终提示词、实际参考和回执；
- 不把视觉样张称为定稿，不执行历史平台。

## 输出

缺失信息或退回 Gate 可直接输出简短结论。需要正式记录时使用 `templates/c_line_feedback_card.md`。如当前授权包含交付组装，按 `_shared/page-brief-batch-execution-rules.md` 的原顺序组装核对数量、缺重错序、媒体对应、跨页衔接与未完成项，保留 Non-A和候选/定稿状态；不新增渲染或课件工程。完成当前授权范围、提出一个必要 Gate 或确定需要退回上游后立即停止。
