# Example: SRT To S07 Shared Brief

Input: `00:01:20-00:02:05` 连续解释两个市场活动区如何共同支撑一个节庆教学点，并提供了两处场地的真实照片。

S 线正确输出：

- 合并理由：同一教学对象与连续解释。
- `s_route: S07_AI课程视觉页型`。
- `visual_assistance_need`：帮助学习者看懂两个活动区与同一节庆教学点的关系。
- 在 `available_materials` 中记录照片路径、来源和可用状态。
- 保留原文、时间码和来源行，然后停止。

S 线不输出标题文案、左右构图、照片占比、模板变体、B 线生产卡或图像生成提示。
