# 反例：混淆内容准入与分页冻结

错误一：缺少实际时间证据时编造时间码，并直接冻结分页。
错误二：把处理范围、Non-A、A线清单、分页理解为必须连续提问四次；用户已批准范围后仍换名重问。
错误三：用户只批准进入A的正文范围，模型却要求先批准8页才能进行A教学复核。

正确做法：先读取本地证据；无时间轴的文稿标明时间码不适用。分别记录Non-A范围、A线文字范围与S候选切分状态；已批准文字范围可以交A做教学复核，候选页数未批准不阻塞分析。未获具体分页批准不得冻结页界。批准Non-A不等于批准其制作方式，拒绝重复回答也不等于批准8页。任何提交审阅的切分方案必须有逐字起止、源定位及完整对应正文；摘要标签不能代替边界。
