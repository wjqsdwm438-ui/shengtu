# Stage S-Line Source Segmentation And Media Routing

## 交互 Gate：先判必要性，再提问

- “核对/快速确认/逐项检查”默认是模型内部工作，不等于逐项向用户索批。提问前先核对当前指令、有效确认和本地证据；相同对象、版本、用途和范围没有变化时沿用，不换名称重问。
- 只有存在会改变下一动作的用户专属决定或缺失授权才提问；必须说明具体未决项、已有结论、推荐方案、影响及被阻塞动作。不能说明回答将改变什么，不得阻塞。
- 一次一个问题约束的是实质决策，不是把一个完整方案拆成机械确认链。先给出可审阅的具体方案；同一范围内的路由清单可随分页方案一并审阅，不另问“是否继续/是否进入下一线”。
- “执行全流程/按规则自行执行到停止点”覆盖所请求范围内的分析与阶段推进；没有实质 Gate 时继续。正式文件写入仍核对目标和写入范围；范围已明确授权则告知后执行，未覆盖才询问。该授权不等于批准尚未展示的分页、设计、参考用途、生图或成品。
- 有效分页、参考用途、设计变更、明确生图授权、代表页确认和最终定稿 Gate 均保留。用户拒绝重复回答不是同意待决方案；回查批准范围，删除重复问题，只保留真正未决的差异。
- 阶段完成先报告结果；仅当授权已用尽或遇到实质 Gate 时停止。本节限定本文“立即停止/只问是否执行”的适用条件，不能用单步默认覆盖明确端到端授权。出现交互冲突时按需读 `_shared/interaction-gate-rules.md`。

## 分页权责与状态分离

- S管理原文证据及Non-A/A线文字准入范围；S切分是候选，不冻结最终页数。A管理教学分组，可以在已批准正文内按教学目标、教学关系和必须呈现项复核拆合；B管理可实现页面方案，不单方面改教学语义；用户最终批准具体执行分页。
- **范围批准是A分析准入条件，分页批准不是A分析前置条件。** “Non-A范围已批准”“A线文字范围已批准”“S候选切分待A复核”“执行分页已批准”分别记录；不使用无对象的“已确认”推导其他授权。
- 原文和准入未变不重跑S；语义问题局部回A，纯实现问题留B，跨页拆合由B给证据、A复核受影响关系。只失效受影响下游结论，不默认整链重启。
- 分页/分组建议必须有源文件、逐字起止（均含）、精确定位及可核验正文；仅有摘要标签不得发起批准。已有正式页拆合须保留旧新映射，不覆盖原S证据。遇到权责、状态或拆合争议时按需读 `_shared/pagination-authority-rules.md`。

## 渐进式读取

### 必读
- 当前 `SKILL.md` 与用户提供的 SRT、讲稿、单页内容或素材清单。
- S 线核对来源文本和素材是否存在，但不查看母版以推导页面设计，也不接收已有页面的构图作为路由依据。
- 不默认读取共享总控、A/B/C Skill、版式细则或视觉示例。

### 按需读取路由
- 一次只允许由当前唯一未决问题触发一个来源；读取后先执行快速确认，再决定是否扩展下一项。
- 只有 S01-S08 相邻路由仍无法区分时，读取 `references/srt_media_routing_rules.md` 的对应条目。
- 只有用户明确要求时间线索引、确定性证据或 ALG-S01 时，读取 `_shared/algorithm-lite-rules.md` 的 ALG-S01 小节并执行对应脚本。
- 只有需要输出正式共享页面简报的 S 区时，读取 `templates/s_line_segment_card.md`。
- 只有已经出现字幕过切风险时，读取 `anti_examples/srt_over_split_failure.md`；已经出现跳过用户确认或用估算代替用户决定时，读取 `anti_examples/pagination_confirmation_skipped_failure.md`；已出现 S 线越界设计时，读取 `anti_examples/s_line_overdesign_failure.md`。

### 快速确认
每次读取后立即确认：源文范围、时间码证据、教学功能、可用素材、候选路由和唯一未决项。一个路由已有充分证据且不存在用户控制项时，停止读取。

### 停止规则
输出当前 S 线结果后停止。即使结果为 `S07_AI课程视觉页型`，也不得自动读取或执行 A线；只有用户明确要求继续到 A线或端到端流程时才跨阶段。

## 职责边界

S 线只负责为后续设计提供可追溯输入：

- 按教学语义合并 SRT/讲稿，保留原文、时间范围和来源行。
- 记录可核对的事实、数据、专有名词及它们的来源。
- 盘点已有图片、视频、截图、文档等素材及其可用状态。
- 判断教学片段是否需要视觉辅助，选择 S01-S08 媒介路由。
- 创建或更新共享页面简报的 `s_section`；下游只能追加所属区域，不得重述或改写 S 区。

S 线不负责页面设计。`visual_assistance_need` 只说明“需要帮助学习者看懂什么”，不能转写为构图、图片占比、容器数量、母版变化或平台提示。

## 阅读与单问题确认顺序

- 本地源文和素材能够消除的信息差先通过只读检查消除；不得把可从 SRT、讲稿或素材清单查明的问题转给用户。
- 先判断当前路由是否确实依赖音频、实际时长或时间码；只有缺少业务必需的时间证据时，才按依赖顺序一次追问一项。无时间轴的文档任务在现有时间字段明确“不适用”及理由，不强要音频、不估算时长。
- 证据齐备后，分别核对Non-A范围、A线文字范围和候选切分状态；已批准文字范围直接交A分析。只在准入范围真有歧义时问用户，不将未批准候选页数当作A分析阻塞。需要用户审阅切分时提交完整边界证据，不机械逐项索批。
- 用户未明确确认分页方案时，不得输出冻结分页；不阻塞已批准文字范围的A教学复核。正式S区只在明确写入授权内记录原文证据与准入范围，必须声明候选页界未冻结，不用S区confirmed代替分页批准。

## DOCX / DOC 多媒体接收

- 先利用用户原稿、已有脚本、素材目录及设计节点产物读懂整体，不强制清洗成统一表格、逐张拆图或重新誊写；节点中的设计决定留给所属阶段核对，不能反向决定 S 路由。
- 保留原文、原顺序与定位，分清旁白正文、屏显文字、制作批注、素材需求和实际已有媒体。原旁白不得改写，批注和制作指令不得混入旁白。
- DOCX 核对正文位置、内嵌/浮动图的关系与锚点、批注范围及其所指内容，不能仅凭解包序号给图片配段落；链接、缓存图与原媒体分别判断。
- “插入视频”“引入盲降的原理视频”等文字只记需求；“图片或视频”仍是未定选项。实际文件已提供且可读、对应内容核对后才记 available；缺文件记 missing，关联或内容未核对记 unverified。
- DOC 解析不足时先局部核对，必要时仅在工作副本本地转 DOCX；位置、裁切或关联仍影响含义时再查看页面预览。未验证的精确排版、浮动图或批注关联必须明示，不宣称完整视觉读取或专业事实已证实。
- 原文、锚点、时间或素材缺口留 S，只阻塞受影响片段；无法可靠路由时用 S08，不让下游猜测，也不要求整课重做。

## Routes
`S01_教师出镜型`, `S02_教师出镜+课程页辅助型`, `S03_视频/现成素材展示型`, `S04_图片/现成素材展示型`, `S05_软件界面/屏幕录制型`, `S06_后期字幕/标注包装型`, `S07_AI课程视觉页型`, `S08_人工确认型`.

## Must Rules
- 不得把 `.srt` 逐句分页。
- 按教学对象、功能与连续性合并相邻字幕，保留 `segment_time_metadata`。
- 不把不需要视觉化的内容强制送入 AI 图像生成。
- 纯过渡或可由教师直接讲清的内容不默认进入 A 线。
- 真实事件、品牌案例、现场表演、展馆空间、软件操作、截图和字幕包装通常不进入 A 线。
- 只有需要长时间停留的课程主页、案例解释页、关系性内容或系列课程页默认进入 A 线。

## 禁止项

S 线不得输出或冻结：

- 页面构图、布局骨架、内容容器或精确位置；
- 图片占比、文字区间或任何固定比例；
- 母版、模板或参考图的继承与变化策略；
- A 线页面设计、B 线生产卡、C 线执行提示或平台提示词；
- 以视觉风格、上一页效果或已有构图决定 S 路由。

## 共享页面简报交接

普通路由结论可直接使用本节字段，不需读取模板。只有需要正式交接时，使用 `templates/s_line_segment_card.md` 创建 `page_brief.s_section`。

S 区必须包含：`page_id`、`original_course_order`、`segment_id`、`segment_time_metadata`、`source_text`、`teaching_function`、`verified_facts`、`available_materials`、`visual_assistance_need`、`recommended_medium`、`s_route`、`enter_A_line`及理由。

S 区交接后为只读证据。A/B/C 必须在同一份 `page_brief` 中追加自己的区域，不得复制出新版“S 线摘要”或改写源文。

## 正式产物与修改返回

写入正式产物前，先说明将生成什么、写到哪里、是否修改已有文件以及下一线实际接收什么，然后只问：`是否按上述产物与交接方案执行？`

已有授权明确覆盖当前文件、分区及写入范围时不重复询问；否则取得用户明确确认后才写入。单阶段授权写完即停；端到端授权按交互Gate规则继续，各阶段只追加所属分区。原文、时间码、事实或素材错误必须返回 S 线更正；下游不得在自己区域覆写。

## Failure / Return
当源材料歧义、当前路由必需的时间码或素材证据缺失、强行路由可能浪费生产成本时，使用 `S08_人工确认型`，且只询问当前缺失的一项决定。
