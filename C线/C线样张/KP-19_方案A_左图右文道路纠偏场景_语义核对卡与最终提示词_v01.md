# KP-19｜原文语义核对卡＋最终提示词 v01

## 一、原文语义核对卡

### 三层来源核对

- 原始微课脚本：针对常温刚需型产品，智能系统设置路线偏离预警，保障货物按最优路线运输，避免绕路增加成本。
- S线冻结功能：方法四·成本监控；解释车辆偏航后如何触发预警并及时纠偏。
- T线冻结：标题、71字正文、L2母版、路线偏离异常点、预警后的及时纠偏及风险控制。

### 冻结因果链

监测车辆位置、规划路线和行驶方向 → 发现偏离最优路线 → 立即预警 → 引导车辆纠偏 → 避免绕路、延误和额外成本。

### 必显文字（逐字冻结）

**标题**

智能监控：路线纠偏

**正文**

监测对象：车辆当前位置、规划路线和行驶方向

异常识别：发现车辆偏离最优路线后立即触发预警

处置结果：引导车辆及时纠偏，避免绕路、延误和额外运输成本

### 差异处理

- S/T线原定“监测输入、偏离异常点与纠偏结果对照”，但用户已明确要求不再用图片承载抽象复杂关系，采用正常单张插图＋右侧文字。
- 本页改用一张普通货车行驶至道路岔口的完整场景插图，仅以一个小型异常警示点提示路线偏离，不画GPS轨迹、地图、监控界面或闭环关系图。
- 监测、预警、纠偏和结果由右侧冻结正文完整表达；不修改T线合同，不删除预警—纠偏因果。
- T线通用提示词存在“生成×1080”“严格保持母版”“主视觉为”等缺省占位，本执行稿仅补全执行信息，不修改合同原文。

左侧约58%放置一张完整、自然、独立的道路运输场景插图：一辆无品牌普通常温厢式货车行驶在简洁的城市外围道路或物流园道路上，前方出现一个清楚但不过度复杂的道路岔口。主道路保持蓝灰色正常通行状态；岔路入口附近只设置一个小型橙红色异常警示点或警示标志，提示车辆可能偏离规划方向。画面同时保留一个克制的蓝色正确方向道路指示，使场景自然表达“发现偏离后及时回到正确方向”。
