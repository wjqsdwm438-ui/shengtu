# KP-17｜原文语义核对卡＋差异化精简提示词 v01

## 一、原文语义核对卡

### 1. 三层来源

- 原始微课脚本：第三种智能赋能方法“全链路动态协同”。针对精益规模降本，系统整合同区域、同方向货物资源，安排整车拼货，以规模化运输压缩成本。
- S线冻结行：页面功能为“方法三·规模协同”；唯一教学动作是解释同向货流如何汇聚形成规模运输。
- T线合同：标题、75字正文、L2母版、开放式关系图、两级焦点及风险控制均已冻结。

### 2. 冻结语义

- 教学主题：动态协同如何服务常温品的规模运输与降本。
- 因果链：同区域/同方向的订单、货物和车辆资源 → 自动汇集货量并匹配车辆 → 安排整车或拼货运输 → 形成规模效应、提高装载率、压缩单位运输成本。
- 第一焦点：自动汇集与车辆匹配。
- 第二焦点：规模运输结果。
- 安全抽象：只表达订单、货物、车辆、主干运输四类节点；不出现真实平台、品牌、地图数据或效率数字。

### 3. 必显文字（逐字冻结）

**标题**

动态协同：规模运输

**正文**

协同对象：同区域、同方向的订单、货物和车辆资源

系统动作：自动汇集货量，匹配车辆并安排整车或拼货运输

优化结果：形成规模效应，提高装载率并压缩单位运输成本

### 4. 差异与执行处理

- 原文只明确“货物资源、整车拼货、规模化运输压缩成本”；冻结正文补充“订单、车辆资源、匹配车辆、提高装载率”，属于S/T线已冻结的教学展开，本页按冻结正文执行，不再扩写。
- T线通用执行句存在“生成×1080”“严格保持母版”“主视觉为”等缺省占位。本次仅在执行提示词中补全为“1920×1080”“严格保持L2冻结母版”“同区域同方向货流汇聚”，不修改T线合同。
- 为区别KP-15，本页不采用三段横向面板，不重复“输入—动作—结果”的分栏结构；改用开放式左入右出的扇入主干构图。

## 二、静态构图方案

- 外层：严格锁定L2母版、顶部标题框和安全边界。
- 主体：大框内采用一幅开放式关系图，不设置三栏、四宫格或多块卡片。
- 左侧约35%：三组疏朗的小型中性物流图示，分别表现同区域订单、同方向货物、车辆资源；最多三条无交叉汇聚线。
- 中央约25%：单一汇聚节点，突出货量自动汇集与车辆匹配；全部扇入线在此合并。
- 右侧约40%：一条粗而清楚的主干运输线，配置无品牌普通货车与整合货物，向右形成规模运输结果。
- 文字布局：第一句放左上作为协同对象说明；第二句贴近中央汇聚动作；第三句放右下作为单一结果收束。三句均完整出现，不拆散改写。
- 视觉动线：左侧多源 → 中央汇聚 → 右侧主干运输；不画网络拓扑，不堆节点。
